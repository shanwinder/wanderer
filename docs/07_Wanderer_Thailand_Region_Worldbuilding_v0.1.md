# 1. เป้าหมายของงานออกแบบแผนที่

1. สร้างโลกหลักที่มีฐานทางภูมิศาสตร์จริงและขยายสู่พื้นที่ข้างเคียงได้ในอนาคต
2. ให้การตัดสินใจเรื่องภูมิประเทศ **มีผลต่อการเดินทาง เควส เสบียง ความเสี่ยง และความสัมพันธ์ NPC** ไม่ใช่ฉากตกแต่ง
3. บอกใบ้ความจริงของโลกเก่าทีละน้อยผ่านสภาพภูมิประเทศ ร่องรอยสิ่งปลูกสร้าง ภาษา และสิ่งของ
4. ให้การพบดาราศิลา/การพ้องพลังหายาก เป็นเหตุการณ์สำคัญ ไม่เปลี่ยนโลกเป็น high-magic
5. รองรับโครงสร้างเกมเดิม: Town UI → Quest → Node Route Map → Event → Combat/เจรจา/หลบเลี่ยง → Return/Reward/Consequences
6. ใช้เอกสารระดับภูมิภาคเป็น **แนวทางภาพและแรงบันดาลใจ** โดยไม่สร้างฟีเจอร์ gameplay ใหม่ก่อนเวลา
7. สร้าง **พื้นที่เล่นจริงขนาดเล็ก (vertical slice)** ที่เชื่อมกับภาพใหญ่ได้โดยไม่ต้อง implement โลกทั้งใบ

## 1.1 สิ่งที่เอกสารนี้ไม่ทำ

- ไม่อ้างว่าเป็นแบบจำลองทำนายประเทศไทยในอนาคต
- ไม่ล็อกพรมแดน การเปลี่ยนแปลงชายฝั่ง ระดับน้ำทะเล หรือเส้นทางแม่น้ำที่แน่นอน
- ไม่กำหนดว่าเชื้อชาติ ภาษา หรือศาสนาในเกมเป็นลูกหลานตรง ๆ จากอัตลักษณ์ร่วมสมัย
- ไม่ทำแผนที่เดินเสรี / open world: เกมเป็น **node-based travel**
- ไม่เล่าว่าสาเหตุการล่มสลายคืออุกกาบาตเพียงอย่างเดียว
- ไม่กำหนดว่าแหล่งดาราศิลาในเกมคือหลุมอุกกาบาตที่มีอยู่จริงทางธรณีวิทยา
- ไม่สร้าง quest, assets หรือโค้ดจากเอกสารนี้โดยอัตโนมัติ

# 2. คำศัพท์และสถานะ

- **[LOCKED — FROM PRIOR PLANS]** โลกหลังอารยธรรมหลายพันปี; ความเป็น post-post-apocalypse; late medieval/early modern; Player คุมตนเอง; NPC autonomy; permadeath; เส้นทางโบราณเป็นแกนเรื่อง; ดาราศิลาหายาก มีจริง ต้องใช้อุปกรณ์และมีต้นทุน
- **[USER DIRECTION]** ให้เหตุการณ์หลักเกิดในภูมิภาคที่เคยเป็นประเทศไทย หลังภูมิประเทศ/สังคม/วัฒนธรรม/ประชากรเปลี่ยนแปลงไปมาก
- **[PROPOSED]** ชื่อภูมิภาคใหม่, ชื่อเมือง, faction, เส้นทาง, สนามทดลอง, โครงประวัติศาสตร์ท้องถิ่น และรูปลักษณ์แผนที่ในฉบับนี้
- **[OPEN]** ตัวเลขปี, ขนาดภัยพิบัติ, รูปร่างชายฝั่ง, การอยู่รอดของซากเฉพาะแห่ง, ตำแหน่งดาราศิลา, ชื่อ Canon, ขนาดพื้นที่เล่นจริง
- **[LATER]** แผนที่โลกนอกคาบสมุทรเอเชียตะวันออกเฉียงใต้, ภาษาเต็มรูป, รายละเอียดรัฐ/กองทัพ/กฎหมายทั้งหมด, เขตการครอบครองระยะไกล

**หมายเหตุ:** ทุกชื่อใหม่ในเอกสารนี้เป็น *working name* แม้เขียนเหมือนชื่อจริงในโลกเกม และแก้ได้หลังทดสอบความรู้สึกของโลก

# 3. โครงกระดูกภูมิศาสตร์จริงที่ใช้เป็นฐาน

## 3.1 สิ่งที่ต้องเคารพ

ภูมิประเทศปัจจุบันของบริเวณนี้มีแกนสำคัญ ได้แก่:
- **แนวภูเขาภาคเหนือและตะวันตก** มีหุบเขา/ลุ่มน้ำระหว่างแนวเขา
- **ที่ราบลุ่มภาคกลาง** รับน้ำจากระบบปิง วัง ยม น่าน และมีเจ้าพระยาเป็นทางน้ำหลักในระบบปัจจุบัน
- **ที่ราบสูงโคราช** ทางตะวันออกเฉียงเหนือ มีพื้นที่ลุ่มน้ำมูล–ชีและเขตตอนเหนือโดยมีแนวภูพานกั้นบางส่วน; เชื่อมกับลุ่มน้ำโขง
- **แนวเขาดงพญาเย็น/สันกำแพง/พนมดงรัก** เป็นตัวกำหนดช่องทางติดต่อระหว่างบางพื้นที่
- **ชายฝั่งอ่าวไทยฝั่งตะวันออก** มีทั้งภูเขาเตี้ย แนวเขา และเมืองท่า
- **คาบสมุทรภาคใต้** อยู่ระหว่างอ่าวไทยกับทะเลอันดามัน และมีแนวภูเขาพาดตามคาบสมุทร

**หลักการ:** แม่น้ำเปลี่ยนทางได้ ปากแม่น้ำและตะกอนเปลี่ยนได้ ชายฝั่งเปลี่ยนได้ แต่ *ไม่ควรเลื่อนแนวเทือกเขาทั้งภูมิภาคหรือสร้างทะเลกลางที่ราบสูงโดยไม่มีเหตุทางโลกชัดเจน*

## 3.2 หมายเหตุด้านวิทยาศาสตร์

- ข้อมูลธรณีวิทยาปัจจุบันเป็น **หลักยึดตำแหน่งสัมพัทธ์** เท่านั้น ไม่ใช่แผนที่อีก 3,000–5,000 ปีในอนาคต
- ชายฝั่งและปากน้ำเปลี่ยนได้จากระดับน้ำทะเล ตะกอน การทรุดตัว การกัดเซาะ และเหตุการณ์รุนแรง แต่ไม่กำหนดตัวเลขน้ำสูงขึ้น/พื้นที่จมโดยอัตโนมัติ
- หากต้องการให้เมืองโบราณแห่งหนึ่งกลายเป็นซากใต้น้ำ ต้องใส่เหตุผลเฉพาะ เช่น พื้นที่ลุ่มต่ำ การทรุดตัว การพังของแนวป้องกันน้ำ การเปลี่ยนร่องน้ำ หรือระดับทะเลระยะยาวตามฉากสมมติ
- ผ่านไปหลายพันปี **อาคารเหล็กและกระจกส่วนใหญ่ไม่ควรอยู่ในสภาพสมบูรณ์**; โครงสร้างคอนกรีตซึ่งเคยใหญ่ก็อาจเหลือเพียงฐาน เสาตอ ซากฝังตะกอน หรือวัสดุที่คนรุ่นหลังนำกลับไปใช้
- อุกกาบาตจาก v0.5 อาจเปลี่ยนสิ่งแวดล้อมบางแห่ง แต่ผลกระทบมหัศจรรย์ไม่จำเป็นต้องสร้างเทือกเขาใหม่ทั้งประเทศ
- แผนที่ฉบับใช้งานต้องแยก **ฐานภูมิศาสตร์โลกจริง**, **การคาดการณ์ตามตรรกะ**, และ **การสร้างสรรค์แฟนตาซี** เป็นคนละชั้นข้อมูล

# 4. เวลาและลำดับประวัติศาสตร์ (ฉบับยังไม่ล็อกปี)

- **Age of the Old World:** อารยธรรมเทคโนโลยีสมัยปัจจุบันก่อนหายนะ
- **The Sundering Sky / คืนฟ้าแตก:** เหตุการณ์จากวัตถุนอกโลกที่เกี่ยวข้องกับดาราศิลา; บทบาทต่อความล่มสลายยัง [OPEN]
- **Long Unraveling:** การล่มของเครือข่ายไฟฟ้า อุตสาหกรรม การขนส่ง รัฐและความรู้จากหลายวิกฤต
- **Generations of Shelter:** ผู้รอดชีวิตกระจายตัวตามลุ่มน้ำ หุบเขา ชายฝั่ง และพื้นที่เกษตรที่ฟื้นตัวได้
- **The Reweaving:** การแลกเปลี่ยน การเกิดภาษา/ความเชื่อใหม่ สมาคมช่าง เส้นทางล่องเรือ และนครรัฐ
- **Era of Roads (ยุคเล่น):** ศูนย์นักผจญภัยกำลังช่วยเปิดเส้นทางที่ถูกตัดขาดระหว่างกลุ่มนครรัฐ

### สิ่งที่ห้ามแอบสมมติ

- ไม่มีคำยืนยันว่าประเทศไทยทั้งประเทศเป็นหนึ่งใน “ศูนย์กลางผู้รอดชีวิต”; ความหนาแน่นประชากรในเกมเกิดจากหลายเหตุ
- วัฒนธรรมที่คล้ายไทยปัจจุบันไม่จำเป็นต้องเป็น “ไทยยุคใหม่” ทั้งหมด
- ประชากรอาจมีเชื้อสายผสมจากการอพยพข้ามภูมิภาคมาหลายพันปีและไม่ได้เรียกตนเองด้วยชื่อชาติพันธุ์/ประเทศปัจจุบัน
- อำนาจของรัฐอาจเกิดและสลายหลายครั้งก่อนยุคเล่น
- อย่าล็อก timeline ก่อนล็อกเรื่องหายนะว่าเฉลยได้มากเพียงใด

# 5. แผนที่โลกใน 3 ขอบเขต

1. **World Context Map** — แสดงเพียงว่าดินแดนหลักอยู่บนโลกจริง ในเอเชียตะวันออกเฉียงใต้; ไม่ต้องวาดมหาสมุทร/รัฐอื่นอย่างละเอียด
2. **Regional Atlas (แผนที่ภูมิภาค)** — พื้นที่ที่เคยเป็นประเทศไทยและขอบเขตติดต่อเชิงภูมิประเทศ; 7 ภูมิภาคหลัก
3. **Playable Route Map** — เมืองและ node ที่เดินทางถึงได้จริงในเกม; เริ่มเพียงเมือง 1, เส้นทาง 2, เหตุการณ์ตามข้อกำหนด Vertical Slice

เกมสามารถใช้พื้นที่ **เฉพาะริมที่ราบสูงโคราช** เป็นจุดเริ่ม แม้แผนที่กระดาษแสดงทั้ง 7 ภูมิภาค เพื่อให้ผู้เล่นรู้สึกว่าโลกกว้างโดยไม่ต้องสร้างระบบทั้งหมดทันที

# 6. Atlas: 7 ภูมิภาคหลัก (ชื่อเสนอ ยังไม่ล็อก)

> **คำเตือน:** ชื่อในคอลัมน์ “พื้นที่อ้างอิงปัจจุบัน” เป็นพิกัดทางความคิดของ *ผู้พัฒนา* ไม่จำเป็นต้องปรากฏในบทสนทนาของคนในโลกใหม่

| ID | ชื่อทำงานในโลกใหม่ | พื้นที่อ้างอิงปัจจุบัน | โครงภูมิประเทศ | ธีมหลัก |
|---|---|---|---|---|
| R1 | **นครหุบเขาสายหมอก** | เหนือ/แอ่งเชียงใหม่–ลำพูน ลำปาง น่านและพื้นที่หุบเขา | ภูเขา หุบเขา ลำห้วย ป่าหลายระดับ | เมืองหุบเขา ความรู้เก่า การต่อรองผ่านช่องเขา |
| R2 | **แนวกำแพงป่าตะวันตก** | ตาก กาญจนบุรี และแนวเทือกเขาทางตะวันตก | สันเขา ช่องเขา แม่น้ำสายป่า | ผ่านแดนยาก คนเดินทางนำทางและผู้รักษาคำสาบาน |
| R3 | **สมาพันธรัฐสี่สายน้ำ** | ที่ราบภาคกลางตอนบน–ตอนล่างและพื้นที่เจ้าพระยาเก่า | ทุ่งตะกอน พื้นที่ชุ่มน้ำ ทางน้ำ/คลอง | ข้าว การค้าทางเรือ ข้อพิพาทน้ำและซากมหานคร |
| R4 | **ทุ่งลมแดงแห่งโครา** | ขอบที่ราบสูงโคราช ลุ่มน้ำมูล–ชีบางส่วน | ที่ราบสูง เนินหิน ดินต่างชนิด ป่าผลัดใบ | เมืองประตู ที่พักคาราวาน ข้อตกลงความไว้ใจ |
| R5 | **ดินแดนสองลุ่มเหนือภูพาน** | แอ่งสกลนครและเขตใกล้ลุ่มน้ำโขงตอนบนในอดีตไทย | แอ่งสูง แนวภูพาน ทุ่งน้ำและแม่น้ำใหญ่ | การข้ามแม่น้ำ ความทรงจำและนครริมน้ำ |
| R6 | **นครอ่าวแก้ว** | ชายฝั่งตะวันออก: ชลบุรี ระยอง จันทบุรี ตราดโดยคร่าว | ชายฝั่ง อ่าว ป่าเขาต่ำ เกาะ | เมืองท่า เครือข่ายช่าง/พ่อค้า อำนาจทะเล |
| R7 | **หมู่เมืองสายฝน** | คาบสมุทรใต้ฝั่งอ่าวไทยและอันดามัน | สันเขากลางคาบสมุทร สองฝั่งทะเล ป่าฝน | ทะเลสองด้าน ภาษาหลากหลาย การค้าและพายุ |

R1/R2 และ R4/R5 มีเขตเปลี่ยนผ่านไม่เป็นเส้นตรง ห้ามอ่านเป็นพรมแดนรัฐสมัยใหม่

# 7. รายละเอียดภูมิภาค (Regional Design Cards)

## R1 — นครหุบเขาสายหมอก

**ภาพจำ:** นาขั้นบันไดที่สืบจากภูมิปัญญาหลายยุค เมืองเล็กระหว่างผาสูง สะพานไม้ใหม่ตั้งอยู่เหนือซากฐานสะพานโบราณซึ่งถูกน้ำกัดเซาะไปมาก

- **ภูมิอากาศ/ทรัพยากร:** ความชื้นเปลี่ยนตามความสูง พืชป่าและผลผลิตหุบเขา; เส้นทางจากต้นน้ำมีฤดูที่อันตราย
- **สังคม:** เครือข่ายนครหุบเขาไม่ใช่อาณาจักรเดียว ต้องเจรจาค่าผ่านทางและความช่วยเหลือ
- **สถาบัน:** บ้านจดบันทึกแผนที่และข่าวภูเขา แข่งกันเก็บรหัสสำรวจ/ภาษาเก่า
- **วัฒนธรรม:** เพลงนำทางและลายผ้าที่บอก “บ้าน/น้ำ/ทาง” มากกว่าชาติพันธุ์ปัจจุบัน
- **ความขัดแย้ง:** ใครมีสิทธิ์เปิดช่องเขาที่เคยกักชุมชนไว้จากกองโจร?
- **โบราณสถาน:** อุโมงค์ภูเขาที่พังเป็นช่วง ตอมอและฐานสื่อสารเป็นจุดนำทาง
- **ดาราศิลา:** บันทึกช่างเกี่ยวกับแสงในเนินหิน ไม่ยืนยันแหล่งแร่
- **Hook:** คุ้มกันผู้ถือแผนที่ซึ่ง NPC ร่วมทางเชื่อว่าควรทำลายเพื่อรักษาความลับหมู่บ้าน

## R2 — แนวกำแพงป่าตะวันตก

**ภาพจำ:** ป่าลึก สันเขาต่อเนื่อง ด่านไม้บนช่องเขา และท้องน้ำที่เปลี่ยนเร็ว

- **ทรัพยากร:** ของป่า ไม้ อาหารตามฤดูกาล หิน/โลหะทั่วไป; ความรู้เดินทางมีราคาสูง
- **สังคม:** ชุมชนห่างไกลรวมตัวเป็นเครือข่ายการคุ้มกันมากกว่ารัฐรวมศูนย์
- **อำนาจ:** สมาคมผู้นำทางได้รับความเชื่อถือจากความจำและความซื่อสัตย์ แต่มีบางกลุ่มใช้ความรู้เพื่อผูกขาดเส้นทาง
- **ความขัดแย้ง:** กลุ่มหนึ่งอยากเปิดทางขนส่ง ขณะที่อีกกลุ่มกลัวโรคและสงครามจากภายนอก
- **โบราณสถาน:** ฐานเขื่อนเก่าหรือถนนฝังตะกอน ซึ่ง **อาจเหลือเพียงส่วนราก** ไม่ใช่เขื่อนพร้อมใช้งาน
- **ดาราศิลา:** พื้นที่ต้องห้ามจากเหตุผลไม่แน่ชัด อาจเป็นดินเปราะ สารจากซากเก่า หรือแร่ผิดปกติ
- **Hook:** ช่วยคนเจ็บข้ามช่องเขา แต่ NPC บางคนปฏิเสธการเสี่ยงข้ามในคืนฝนแรง

## R3 — สมาพันธรัฐสี่สายน้ำ

**ภาพจำ:** เมืองลำน้ำและเรือนตลาดบนฝั่งสูง ร่องแม่น้ำแยกแขนง ทุ่งน้ำตามฤดู และซากนครที่ถูกตะกอนกลบ

- **ภูมิประเทศ:** ได้แรงจากระบบลำน้ำปิง–วัง–ยม–น่าน/เจ้าพระยาในปัจจุบัน แต่ตำแหน่งลำน้ำยุคเกมยัง [OPEN]
- **สังคม:** สภาเมืองที่ทำข้อตกลงเรื่องน้ำ การเพาะปลูก การขนส่งและอากรตลาด
- **วัฒนธรรม:** แผ่นไม้บันทึกระดับน้ำ พิธีเริ่มฤดูเรือ; อาจมีคำเก่าเพี้ยนมาจากภาษาหลายยุค
- **ความขัดแย้ง:** การกั้นน้ำหนึ่งเมืองทำให้เมืองปลายน้ำอดอยาก; เลือกช่วยใคร?
- **โบราณสถาน:** ชั้นฐานเมืองเก่าใต้ดินโคลน/ตะกอน แนวถนนยกระดับเหลือเป็นคันสูงไม่ต่อเนื่อง; บางจุดกลายเป็นเกาะกลางน้ำ
- **ดาราศิลา:** พ่อค้าเก็บของเก่ามูลค่าสูงแต่ไม่ได้ทำให้การใช้พลังเป็นเรื่องประจำวัน
- **Hook:** คุ้มกันเรือเสบียงผ่านพื้นที่ซึ่งชนชั้นปกครองห้ามข้ามเพราะพิพาทสิทธิใช้น้ำ

## R4 — ทุ่งลมแดงแห่งโครา

**ภาพจำ:** ทุ่งสูงสลับแนวป่าและเนินดินแดง ลมฝุ่นในหน้าแล้ง เมืองป้อมเล็กคุมทางผ่าน และซากทางขนส่งโบราณซึ่งตัดข้ามภูมิประเทศ

- **ภูมิประเทศ:** ขอบที่ราบสูงทางตะวันตกเป็นประตูธรรมชาติสู่ที่ราบสูงโคราช; ภายในมีลุ่มน้ำ/ที่ราบหลากหลาย ไม่กำหนดว่าเป็นทะเลทรายทั้งหมด
- **สังคม:** เมืองประตูเก็บค่าผ่านทาง; สมาคมคาราวานมีสัญญาคุ้มกันและบันทึกความเชื่อถือ
- **วัฒนธรรม:** การต้อนรับแขกและสัญญาปลอดภัยมีน้ำหนักทางศีลธรรม เพราะเส้นทางไกลและเสบียงจำกัด
- **ความขัดแย้ง:** เมืองปิดทางผ่านเพื่อรักษาเสบียง แต่ทำให้เมืองอีกฝั่งขาดยา; คนคุ้มกันต้องเลือกทำตามคำสั่งหรือช่วยผู้เดือดร้อน
- **โบราณสถาน:** คันทางรถไฟ/ทางหลวง, ตอสะพาน, อุโมงค์ฐานเขาที่ถูกปิด ไม่ใช่รถไฟสภาพพร้อมใช้
- **ดาราศิลา:** ตำนานว่า “เสาตะวันตกส่องแสงเมื่อพายุมา” แต่หลักฐานจริงยัง [OPEN]
- **Hook:** เส้นทางหนึ่งปลอดภัยแต่ต้องผ่านการเมืองของด่าน อีกเส้นผ่านซากอุโมงค์ซึ่งสัญญาณเข็มทิศผิดปกติ

## R5 — ดินแดนสองลุ่มเหนือภูพาน

**ภาพจำ:** แอ่งกว้างที่มีดินน้ำชื้นกับผืนป่าบนสันภูพาน ท่าเรือชุมชนริมแม่น้ำ และฤดูกาลน้ำเปลี่ยน

- **ภูมิประเทศ:** ภูพานเป็นแนวเปลี่ยนเขตเชิงภูมิประเทศไปสู่แอ่งตอนเหนือ; ลุ่มน้ำโขงยังเป็นแกนภูมิภาคของเอเชียตะวันออกเฉียงใต้
- **สังคม:** นครริมน้ำค้ากับฝั่งตรงข้ามซึ่งไม่จำเป็นต้องเป็น “ต่างประเทศ” แบบปัจจุบัน
- **วัฒนธรรม:** เรื่องเล่าความทรงจำเป็นเพลง/ลายแกะไม้ เน้นการเดินเรือและการรักษาสัญญา
- **ความขัดแย้ง:** น้ำลดเผยซากเมืองเก่า; กลุ่มคนเถียงกันว่าต้องเก็บความรู้หรือปล่อยซากเป็นสุสาน
- **โบราณสถาน:** ซากแนวตลิ่ง เสาคอนกรีตโบราณบางส่วน และชั้นอาคารถูกป่าหรือแม่น้ำกลืน
- **ดาราศิลา:** มีเครื่องรางสืบทอดเพียงชิ้นเดียวที่คนทั่วไปเคยเห็นทำงานจริงในพิธีสำคัญ
- **Hook:** NPC ผู้เห็นค่าความทรงจำต้องเลือกช่วยผู้ร่วมทางหรือปกป้องของสืบตระกูลเมื่อเรือล่ม

## R6 — นครอ่าวแก้ว

**ภาพจำ:** เมืองท่าหลายเครือข่าย ทุ่นเรือและป้อมดูแลปากอ่าว ช่างแก้ว/โลหะกับเรือจากแดนไกล

- **ภูมิประเทศ:** อ่าวและเกาะของชายฝั่งตะวันออกเป็นฐาน; ชายฝั่งในยุคเกมเปลี่ยนรูปร่างได้ตามหลัก [OPEN] §3
- **สังคม:** นครท่าอิสระมีสมาคมพ่อค้า ช่าง และผู้รักษาประภาคาร/ท่า
- **วัฒนธรรม:** ภาษาการค้าลูกผสม ป้ายภาพมากกว่าข้อความยาว คำยืมต่างถิ่นเป็นเรื่องธรรมดา
- **ความขัดแย้ง:** การค้าของหายากขัดกับความปลอดภัยของท่าและการเอาเปรียบชุมชนเหมือง
- **โบราณสถาน:** ฐานท่าเรืออุตสาหกรรมเก่าหรือชั้นเหล็กผุซึ่งคนรุ่นหลังเรียกว่า “สุสานเรือเหล็ก”
- **ดาราศิลา:** มีผู้ประเมิน/ของปลอม/การสั่งทำอุปกรณ์เฉพาะ แต่ไม่ได้มีของจริงวางขายทั่วไป
- **Hook:** คุ้มกันพ่อค้าซึ่งแอบขนผลึกแตกร้าวและต้องตัดสินใจระหว่างค่าจ้างกับอันตรายแก่ผู้ร่วมทาง

## R7 — หมู่เมืองสายฝน

**ภาพจำ:** ทางข้ามคอคอด เสียงฝน ป่าหนาทึบ เมืองท่าทั้งสองทะเล และความหลากหลายของภาษา/วัฒนธรรมที่เกิดจากการติดต่อระยะยาว

- **ภูมิประเทศ:** แนวเขาคาบสมุทรกั้นเส้นทางข้ามสองฝั่ง น้ำและลมมรสุมกำหนดฤดูกาลเดินทาง; ไม่สมมติว่าคาบสมุทรขาดจากแผ่นดินโดยอัตโนมัติ
- **สังคม:** เครือเมืองชายฝั่งบางแห่งค้ากัน บางแห่งแข่งขัน มีคนจากหลายถิ่นอาศัยร่วมกัน
- **วัฒนธรรม:** พิธีออกเรือ ปฏิทินลม การตั้งชื่อกลุ่มตามท่า/อาชีพ มากกว่าการโยงชาติพันธุ์ปัจจุบันแบบตรงตัว
- **ความขัดแย้ง:** การเปลี่ยนเส้นทางเรือทำให้เมืองหนึ่งรุ่งและอีกเมืองยากจน
- **โบราณสถาน:** ซากถนนขึ้นเขา สะพานฐานหิน ถนนทางเกวียนที่สร้างทับซากโครงทางเก่า
- **ดาราศิลา:** ข่าวลือวัตถุเรืองแสงในซากใต้ทะเลยังไม่ยืนยันว่าเป็นของจริง
- **Hook:** คุ้มกันผู้สำรวจที่มีแผนที่ทางข้ามฝน โดยต้องตัดสินใจพึ่งไกด์คนใดในปาร์ตี้

# 8. ไม่ทำให้ทุกภูมิภาคเป็น “ประเทศเดียวต่อหนึ่งวัฒนธรรม”

- ทั้ง 7 ภูมิภาคเป็น **ecological/cultural design region** ไม่ใช่รัฐที่มีพรมแดนตรงทับภูมิศาสตร์
- แต่ละภูมิภาคมีหลายเมือง หลายภาษาและหลายความเชื่อ; ความเป็นนครรัฐเกิดจากการค้า อาหาร น้ำ ความปลอดภัยและประวัติการอพยพ
- วัฒนธรรมผสมเป็นเรื่องปกติ การคงอยู่ของคำ/สิ่งของ/ศิลปะโลกเก่าอาจขาดช่วงแล้วถูกตีความใหม่
- ไม่เสนอว่า “คนเหนือเป็นแบบหนึ่ง คนอีสานเป็นแบบหนึ่ง คนใต้เป็นแบบหนึ่ง” ในลักษณะ stereotype; ลักษณะทางศีลธรรมของ NPC ขึ้นกับประวัติ **ปัจเจกบุคคล** เป็นหลัก
- ไม่ยึดเชื้อชาติ ศาสนา หรือตัวตนร่วมสมัยเพื่อกำหนดความเก่งทางการต่อสู้หรือความเป็นคนดี/ชั่ว
- เมืองใกล้พรมแดนเก่าอาจมีเครือข่ายภาษา/ครอบครัวจากหลายด้าน โดยผู้คนไม่รู้เส้นชายแดนเดิมด้วยซ้ำ

# 9. เครือข่ายการเดินทาง: แผนที่ก่อนการเดินทางจริง

## 9.1 ปรัชญาเส้นทาง

เส้นทางแต่ละเส้นมี **ค่าแลกเปลี่ยน** ไม่ใช่เพียงไกล/ใกล้:
- เวลาและเสบียง
- ฤดู/ฝน/ระดับน้ำ/ความร้อน
- ความเสี่ยงปะทะหรือโรค
- ค่าผ่านทางหรือสิทธิทางการเมือง
- ความรู้/ไกด์ท้องถิ่น
- โอกาสบาดเจ็บและการพยุงผู้บาดเจ็บ
- ข่าวลือเกี่ยวกับโลกเก่าหรือดาราศิลา
- ความคิดเห็น/ความไว้ใจของ NPC แต่ละคน

# 11. ดาราศิลาในภูมิภาคหลัก

**เอกสาร [05] มีอำนาจกำหนดกฎพลัง**: Starstone ไม่ใช่แร่ธรรมดาที่พบกระจายทุกเขต; พลังต้องมีผลึก+อุปกรณ์+ตัวกระตุ้น, จำกัดต้นทุน, คนทั่วไปทราบว่าพลังมีแต่พบเห็นยาก

## 11.1 ระดับการพบ (เชิงเรื่องเล่า ไม่ใช่อัตราดรอป)

- **Rumor:** เรื่องเล่าและความเชื่อซึ่งพิสูจน์ไม่ได้
- **Known Object:** มีของจริงอยู่หนึ่งชิ้นในชุมชน/กลุ่มนักผจญภัย
- **Known Workshop:** เมืองใหญ่มีช่างตรวจ/ซ่อมได้บางชนิด
- **Possible Source:** มีหลักฐานสอดคล้องการตกของวัสดุ แต่ยังไม่ยืนยันหรือเข้าถึงง่าย
- **Restricted Zone:** พื้นที่เสี่ยงสูงหรือมีคนปิดกั้น ซึ่ง *อาจ* เชื่อมกับวัสดุ

ไม่แจกสัดส่วนพบหรือจำนวนหินจนกว่า gameplay/balance พร้อม

## 11.2 เส้นเรื่องดาราศิลาที่เสนอ

1. R4 มีข่าวลือเรื่อง “เสาฟ้า” ใกล้ทางที่ถูกปิด: **Rumor** ไม่ใช่ประกาศแหล่งแร่
2. R5 มีจี้สืบทอดที่เคยช่วยประคองผู้บาดเจ็บ: **Known Object** และมีราคา/ผลเสีย
3. R6 มีผู้ประเมินและของปลอม: **Known Workshop / Market** ไม่ใช่เหมืองแร่เต็มภูมิภาค
4. R1 มีบันทึกผิดยุคที่พูดถึงรอยตกซ้ำหลายจุด: **Conflicting Evidence**
5. จุดที่สัมพันธ์กับคืนฟ้าแตก **ยังไม่กำหนดพิกัดและความจริงแท้** ใน v0.1; ใช้เป็นปริศนาในอนาคต

# 12. การเมือง เศรษฐกิจ และความทรงจำ

## 12.1 โครงสร้างปกครองที่หลากหลาย

- นครรัฐการค้า
- สมาพันธรัฐลุ่มน้ำ
- ด่านเก็บค่าผ่านทางที่กึ่งอิสระ
- เครือข่ายท่าเรือ
- สภาช่าง/สมาคมการคุ้มกันที่มีอิทธิพลมากกว่ารัฐในบางพื้นที่
- ชุมชนหุบเขาซึ่งประชุมกันเมื่อมีภัยร่วม

ไม่ให้ **ทุกเมืองมีสมาคมนักผจญภัยเหมือนสาขาธนาคาร**; ความเชื่อถือของสมาคมเกิดจากงานจริงและการยอมรับในท้องถิ่น

## 12.2 เงินและการค้า [OPEN]

ตัวอย่างทรัพยากรสำคัญ: ข้าว/อาหารแห้ง เกลือ ไม้ เชือก โลหะ ผ้า สัตว์บรรทุก ยารักษา แผนที่ ข่าวสาร ช่างซ่อม และของหายาก

- การค้าแร่พลังเป็นเพียง **ยอดเล็กแต่ความหมายสูง** ของระบบเศรษฐกิจ
- กำไรจากการเปิดเส้นทางอาจสำคัญกว่าการเจอสมบัติ
- วัฒนธรรมต้องสัมพันธ์กับการหาอาหาร/น้ำ/ทาง ไม่ใช่เพียงสีเสื้อและสถาปัตยกรรม
- เครือข่ายข้ามทะเล/แม่น้ำคือปัจจัยที่ทำให้วัฒนธรรมผสม ไม่ใช่รัฐเดียวครอบครองทุกฝ่าย

## 12.3 ศูนย์นักผจญภัย

คงบทบาทเดิม v0.1:
- กระดานเควส/ข้อมูลเส้นทาง
- ชักชวน NPC
- ประเมินข่าวและความเสี่ยง
- ระบบชื่อเสียง/ใบอนุญาต
- บันทึกผู้ตาย/ของฝาก/เส้นทางที่เปิดแล้ว

เพิ่มบริบทภูมิศาสตร์ด้วย **ข่าวที่มีความน่าเชื่อถือต่างกัน** มากกว่าขยายระบบกลไกใหม่

# 13. ภาษา สังคม วัฒนธรรม และผู้รอดชีวิต

## 13.1 หลักการ

ภาษาใหม่อาจเก็บเสียง/คำ/รูปอักษรจากโลกเก่าบางส่วน แต่เมื่อเวลาผ่านหลายพันปี **ไม่ควรให้ทุกเมืองพูดภาษาไทยร่วมสมัยเหมือนไม่มีอะไรเกิดขึ้น** เว้นแต่คำพูดที่ผู้เล่นเห็นคือระบบแปลเพื่อความเข้าใจ

วัฒนธรรมเกิดจากการสืบทอด **และ** การประดิษฐ์ใหม่ การผสมข้ามกลุ่ม และความทรงจำที่บิดเบือน ไม่ใช่แค่การ rename วัฒนธรรมปัจจุบัน

## 13.2 กลยุทธ์การเขียนบทสนทนา

- แสดงภาษาหลักในเกมเป็นภาษาไทยที่อ่านรู้เรื่องในฐานะ **translation convention**; ชื่อเฉพาะ/ป้าย/สำนวนทำให้รู้สึกวัฒนธรรมต่าง
- กำหนด 2–3 สำนวนประจำเมืองที่สัมพันธ์ภูมิประเทศและอาชีพ แทนสร้างภาษาประดิษฐ์ครบทุกคำ
- ให้ผู้คนมองโลกเก่าต่างกัน; ความเชื่อเรื่องคืนฟ้าแตกเป็นเรื่องเล่าหลากฉบับ
- ศาสนาในโลกใหม่อาจมีหลายระบบความเชื่อ ไม่ผูกแบบหนึ่งต่อจังหวัดเดิม
- หลีกเลี่ยงการใช้ศาสนา/ภาษา/ชาติพันธุ์ปัจจุบันเป็น “enemy faction” แบบตายตัว

## 13.3 Survivor Lineages [OPEN]

- ผู้รอดชีวิตจากโลกเก่าอาจมาจากเมืองใหญ่ ชนบท ชายฝั่ง ชุมชนข้ามแดน หรือการอพยพในยุควิกฤต
- เรา **ไม่รู้** ว่าแหล่งใดเหลือรอดมากที่สุดก่อนตัดสิน nature of collapse
- ประชากรปัจจุบันในเกมมีภูมิลำเนาและเครือญาติที่เกิดในยุคใหม่เอง
- สิ่งที่เหลือจากอารยธรรมเดิมเป็น *ร่องรอยความหมาย* ไม่ได้ทำให้กลุ่มใดมีสายเลือดพิเศษในการใช้ Starstone

## 17.1 ข้อกำหนดแผนที่ (Map Brief) สำหรับ MAP-01

- รูป: แผ่นดินของไทยปัจจุบันแบบมีเขตข้างเคียงพอให้เห็นทิศโดยรวม; ไม่ต้องแสดงเส้นจังหวัด/รัฐปัจจุบันในภาพ final
- ทิศ: เหนือขึ้นบน สัดส่วนไม่จำเป็นต้องแม่นขั้น GIS ในรอบแรก แต่ต้องไม่สลับตำแหน่งภาค
- ลำดับการวางภาพ: ภูเขา → ระบบแม่น้ำ → ที่ราบสูง → คาบสมุทร/ชายฝั่ง → เขตชีวนิเวศสมมติ → ชื่อภูมิภาค
- ข้อกำหนดสำคัญ: 7 region เป็น *พื้นที่อิทธิพล* ขอบนุ่ม ไม่ใช่ polygon แบ่งจังหวัด
- แยกภาพ “ผู้เล่นเห็น” ออกจากภาพ “ผู้สร้างรู้”; อย่าใส่ crater truth หรือเนื้อเรื่องคืนชีพบนแผนที่ public
- สไตล์ในโลก: แผนที่หนังสัตว์/กระดาษหยาบที่นักเดินทางวาดตามข้อมูลไม่สมบูรณ์; รูปร่าง **ตั้งใจคลาดเคลื่อนบางส่วน** ได้ *หลัง* มี reference map ถูกหลัก
- Icon สี/สัญลักษณ์ต้องอ่านออกแม้ขาวดำ; อย่าใช้สีอย่างเดียวบอกระดับอันตราย
- ให้ผู้เล่นมีที่ว่างจดหมายเหตุ เส้นทางใหม่ หรือคำเตือนจาก NPC

# 18. Narrative Opportunities ที่ตั้งใจเปิดไว้

- คนโลกใหม่อาจไม่รู้จักคำว่า “ไทย” เลย แต่ผู้เล่นค่อย ๆ สังเกตซากอาคาร/รูปสัญลักษณ์ที่ทำให้คิดได้ว่าเป็นภูมิภาคไทยโบราณ
- รูปทรง “ถนนสายใหญ่” และลำน้ำเชื่อมเมืองที่ผู้เล่นค่อย ๆ เปิด สอดคล้องกับธีมการสร้างเครือข่ายใหม่จากซากการเดินทางเดิม
- ประวัติศาสตร์ของคนรอดไม่ได้เป็นคำบอกเล่าชุดเดียว: ซากเดียวอาจเป็นสมบัติ ศาสนสถาน แหล่งแร่ หรือคำเตือนอันตรายของแต่ละชุมชน
- ข่าวลืออุกกาบาตอาจนำคาราวานเข้าที่ห้าม แต่ผู้เล่นยังไม่รู้ว่าพลังนั้นจริงหรือผลจากการสืบต่อคำผิด
- คนร่วมทีมที่มาจากต่างเขตอาจไม่เห็นด้วยว่าเปิดเส้นทางบางสายคือ “ความก้าวหน้า” หรือ “การรุกราน”
- หลังสมาชิกตาย บันทึกและข้อมูลเส้นทางที่ยังอยู่ทำให้การเดินทางครั้งใหม่มีความหมายตาม meta progression เดิม

# 23. หลักฐานภูมิศาสตร์และแหล่งอ้างอิงประกอบ

**แหล่งต่อไปนี้ใช้อ้างอิงเฉพาะภูมิประเทศของประเทศไทยในยุคปัจจุบัน ไม่ได้ยืนยันเรื่องราวอนาคตหรือข้อสมมติใน Wanderer**

1. กรมทรัพยากรธรณี — [ธรณีวิทยาประเทศไทย](https://www.dmr.go.th/ด้านธรณีวิทยา/ธรณีวิทยาพื้นฐาน/ธรณีวิทยาประเทศไทย/) — ลุ่มเจ้าพระยา แนวภูเขา ธรณีสัณฐานปัจจุบัน
2. กรมพัฒนาที่ดิน — [Physiographic Regions](https://webeng.ldd.go.th/pv/?cd=227&lv=2) — กรอบแนวภูเขาและที่ราบสูงโคราช
3. Mekong River Commission — [Geography](https://www.mrcmekong.org/geography/) — ระบบลุ่มน้ำโขงและพื้นที่ที่ราบสูงโคราช
4. กรมอุตุนิยมวิทยา — [ภูมิอากาศของประเทศไทย](https://www5.tmd.go.th/info/ภูมิอากาศของประเทศไทย) — รูปแบบภูมิอากาศปัจจุบันเพื่อใช้เป็นเบื้องหลังของฤดูกาล
5. งานวิจัยที่ตีพิมพ์ปี 2025 — [Projected sea-level rise in Thailand](https://online.ucpress.edu/elementa/article/13/1/00069/209819/Projected-sea-level-rise-in-Thailand-Regional) — ความไม่แน่นอนเรื่องระดับทะเลและการเคลื่อนตัวในแนวดิ่ง; **ไม่ใช่การคาดการณ์ครอบคลุมหลายพันปี**

## หมายเหตุปิดท้าย

นี่เป็นเอกสาร **“เข็มทิศสำหรับสร้างโลก”** ไม่ใช่ข้อกำหนดให้ผลิตแผนที่สวยทั้งหมดก่อนเกมเล่นได้ เป้าหมายคือให้ผู้พัฒนามีแรงอยากสร้าง Wanderer ต่อ ขณะเดียวกันทำให้โลกในเกมมีเอกลักษณ์และมีกฎที่ตรวจย้อนกลับได้

**คำถามต่อไปที่สำคัญที่สุด:** เมื่อเห็น MAP-01 แบบหยาบแล้ว ผู้สร้างยังอยากเดินทางในโลกนี้หรือไม่? ถ้าอยาก — ค่อยสร้างตำนานและเมืองเพิ่ม หากไม่ — ปรับโลกได้ทันทีโดยต้นทุนต่ำ
