# 2. สองชั้นความจริงต้องไม่ปะปนกัน

### A. Designer truth — ผู้สร้างต้องรู้
- พื้นที่ใหญ่โดยแกนภูมิศาสตร์สัมพันธ์กับ **ดินแดนที่เคยเป็นประเทศไทยและบางส่วนของภูมิภาคข้างเคียง**
- Reference geography: ที่ราบสูงโคราช, ระบบลุ่มน้ำกลาง, แนวภูพาน, ลุ่มโขง, คาบสมุทร ฯลฯ
- จุดที่ใช้เทียบ Stonegate: บริเวณแนวปากช่อง–ลำตะคองปัจจุบันโดยคร่าว (ยังไม่มีพิกัด Canon)
- การเปลี่ยนภูมิประเทศต้องสมเหตุสมผล; ห้ามทำลายความจริงเพื่อซ่อนเฉลย

### B. Player truth — สิ่งที่ผู้เล่นรู้ ณ ตอนนั้น
- ภูมิภาคและเมืองมี **ชื่อที่ผู้คนยุคเกมตั้งเอง**; ไม่มีใครต้องเรียกสิ่งต่าง ๆ ว่า “ประเทศไทย” หรือจังหวัดเดิม
- คนในโลกไม่อธิบายอดีตเป็นคู่มือภูมิศาสตร์; มีแต่ข่าวของเก่าและข้อมูลที่ไม่สมบูรณ์
- แผนที่เริ่มต้นเป็น **แผนที่การเดินทางในพื้นที่แคบ** ไม่ใช่แผนที่ทางการศึกษาของทั้งแผ่นดิน
- ตัวละครอาจรู้ว่ามี “ยุคก่อนฟ้าแตก” แต่ไม่ได้แปลว่ารู้ชื่อรัฐชาติในช่วงเวลานั้น
- UI เขียนภาษาไทยได้ด้วย **translation convention** — ภาษา UI ไม่ใช่หลักฐานว่าคนทั้งโลกพูดไทยมาตรฐานเมื่อหลายพันปีก่อน

**ข้อกำหนดงานผลิต:** ไฟล์ข้อมูล Designer Truth **ห้ามนำเข้า runtime resources, localization tables, exported UI, Store description, press kit, trailer/subtitle, achievements หรือ screenshot ที่เปิดเผยชื่อเก่า** โดยไม่ได้ผ่านขั้นเปิดเผยตามนโยบายนี้

### 3.1 ชื่อที่ “ดูเป็นไทย” ไม่เท่ากับหลักฐานทางภูมิศาสตร์

- ชื่อคน เช่น คีริน เมียร่า รอนโด อาริน คอล ลาเวน เป็นความหลากหลายของชุมชนใหม่ ไม่ใช่คำเฉลย
- เครื่องแต่งกาย อาหาร เครื่องมือ และพิธีต่าง ๆ ไม่ควรกลายเป็นชุดภาพจำการท่องเที่ยวไทยอย่างประจวบกันหลายรายการ
- ใช้ลักษณะทางวัฒนธรรมร่วมของเอเชียตะวันออกเฉียงใต้ได้ตามเหตุผลการสืบทอด แต่ **อย่าให้ NPC พูดชื่อประเพณี/ราชวงศ์/จังหวัดร่วมสมัยตรง ๆ ก่อนช่วงปลาย**
- ไม่ควรแก้ปัญหาด้วยการทำให้วัฒนธรรมไร้ราก; โลกต้องมีรายละเอียดจริง แต่ไม่ให้กลุ่มเบาะแสชี้คำตอบทันที

# 4. Reveal Ladder — เปิดความจริงตามความคืบหน้าการเล่น

| ระดับ | ช่วงเกม/เกณฑ์ | สิ่งที่ผู้เล่นเห็น | สิ่งที่ต้องห้าม |

| **R0 — โลกของคนปัจจุบัน** | เปิดเกม / เมือง Stonegate / Q1–Q3 / Vertical Slice แรก | เมืองด่าน การค้าคาราวาน NPC เลือกเอง ซากไม่ชี้ประเทศ; รู้ว่ามีโลกเก่า | ห้ามชื่อไทยปัจจุบัน แผนที่ประเทศเต็ม เศษป้ายภาษาไทยอ่านออกตรง ๆ |

| **R4 — โลกเดิมเปิดตัวตน** | หลังผู้เล่นค้นพบ R3 แล้วและเลือกตามข้อมูลต่อ (อาจเป็น optional discovery) | เศษบันทึกเก่า/แผนที่ยุคก่อนยืนยันว่าดินแดนนี้มีความเกี่ยวข้องกับพื้นที่ที่เคยเรียก “ไทย” | ห้ามทำให้ตัวละครทุกคนรู้จักประเทศไทยทันที; เนื้อเรื่องยังเป็นโลกใหม่ของพวกเขา |

**ข้อกำหนด R2:** หลักฐาน 3 ชิ้นต้องเป็น **independent clues** ไม่ใช่ป้ายคำไทยสามป้ายแปะเรียงกัน; อย่างน้อยหนึ่งชิ้นต้องมาจากการสืบและเลือกเดินทาง ไม่ใช่คัตซีนอัตโนมัติ

**ประสบการณ์สองกลุ่ม:** ผู้เล่นที่รู้จักภูมิประเทศไทยดีอาจเดาใน R2 ก่อนคนอื่น — **นั่นคือผลลัพธ์ที่ต้องการ**; คนที่ไม่รู้บริบทสามารถเข้าใจความสำคัญของการพบซากโดยไม่ต้องผ่านแบบทดสอบภูมิศาสตร์

# 5. Evidence Design — เบาะแสจากจางไปชัด

## 5.1 R0 (เมืองเริ่มต้น): ไม่วางป้ายบอกคำตอบ

**อนุญาต:** ฐานสะพานคอนกรีตพัง, คันทางโบราณถูกหญ้ากลบ, เครื่องหมายช่างที่คล้ายรหัส, เสาแปลกซึ่งอาจเป็นหอค้ำทาง, ข่าวว่าโลกเก่าเดินทางได้เร็วกว่าปัจจุบัน

**ห้าม:** หลักกิโลเมตรที่อ่าน “ปากช่อง”, แผนที่รูปประเทศไทยครบ, หมายเลขทางหลวงไทยบนจอ, ป้ายธงไทย, สัญลักษณ์ราชการไทยซึ่งอ่านออก, ชื่อ “เขาใหญ่” หรือ “มิตรภาพ” ชัดเจน

## 5.2 R1 (ความรู้สึกคุ้นเคย)

ตัวอย่าง: มุมหนึ่งของซากคันทางที่หันข้ามช่องเขา ข้อความบนเศษป้ายเหลือเพียงส่วนรูปอักษรไร้ความหมายสำหรับ NPC ปัจจุบัน, รายงานป่าและทางน้ำที่ต่างกันระหว่างแผนที่โบราณกับแผนที่ใหม่

**ข้อควรระวัง:** อย่าใช้รูปร่างแผ่นดินทั้งประเทศเป็นภาพ Background ตอนผู้เล่นยังอยู่ R1

## 5.3 R2 (ต่อจุด)

สามแกนหลักของหลักฐานที่เสนอ:

- **Geographic clue:** ผู้เล่นได้แผนที่ร่างเก่าและเดินทางไปเห็นแนวทาง/ที่สูงซึ่งสัมพันธ์กับแผนที่เศษหนึ่ง
- **Infrastructure clue:** ซากทางที่ผ่านบริเวณรอยต่อ R3/R4 และการออกแบบที่ดูเป็นโลกยุคก่อน ไม่ใช่ถนนของโลกใหม่
- **Language/object clue:** วัสดุปิดผนึกยุคเก่าที่มีเครื่องหมายคล้ายอักษร ซึ่งต้องจับคู่กับตำราหรือพยานช่างผู้ชำนาญจึงอ่านได้บางส่วน

ต้องมีแหล่งที่มาชัดแต่ไม่ต้องสร้างแปลอักษรทั้งระบบ

## 5.4 R3 / R4 (moment of recognition)

**ตัวอย่างปลายเกม [PROPOSED, NOT CANON]:** หลังผู้เล่นรวบรวมเบาะแสจากหลายพื้นที่ พบภาชนะหรือป้ายยุคเก่าที่มีคำส่วนหนึ่งอ่านว่า **“ปากช่อง”** หรือ “นครราชสีมา” พร้อมแผนผังทางซึ่งเทียบกับเส้นทางที่เคยเดินได้จริง ผู้เล่นบางกลุ่มเชื่อมเองทันที; อีกกลุ่มอาจยังสงสัยจนพบแผนที่อีกชั้นภายหลัง

- “ปากช่อง” **ห้ามอยู่ใน Vertical Slice**
- ไม่ใช้คำที่อ่านตรงทั้งประโยคใน R0
- ไม่จำเป็นต้องใช้ชื่อจริงทั้งสอง; ต้องตรวจลำดับการพบ/ความถูกต้องของพื้นที่ก่อนอนุมัติ
- ผู้พูดในโลกใหม่อาจอ่านอักษรนั้นไม่ออกและเรียกมันว่า “อักขระคนก่อน”; ผู้เล่นที่อ่านไทยได้จะเกิดการเชื่อมโยงเร็วกว่าคนในเกม
- **อย่าให้ UI อธิบายว่า “คุณค้นพบประเทศไทย”** ความรู้สึกควรเป็นของผู้เล่น

# 6. Fog of Knowledge & Cartography

## 6.1 ออกเกมแบบ node-based ตาม [01]

- ผู้เล่นเริ่มต้นด้วย **Stonegate + Route A/B เท่านั้น** ไม่เปิด Regional Atlas ของ R1–R7 ทั้งหมดตั้งแต่เมนูแรก
- ข้อมูลส่วนภูมิภาคเป็นการได้ยินข่าว/รู้จักพ่อค้า ไม่ใช่เห็น silhouette ทั้งประเทศ
- แผนที่เพิ่มข้อมูลจาก **เดินทาง, คุยกับ NPC, สำรวจและยืนยันข่าว** โดยแยกชั้น “เชื่อ” กับ “ยืนยัน”
- จะเปิด map แบบ panorama/full macro region ได้ต่อเมื่อเล่นไปไกลตาม story gate และยังไม่จำเป็นต้องมีเส้นประเทศเก่าทับอยู่
- ชิ้นแผนที่โลกเก่าควรอยู่ใน **designer-only layer** ก่อน ถึง R2–R4 จึงค่อยได้ asset ที่ออกแบบให้ผู้เล่นเห็น

## 6.2 สัญลักษณ์และ orientation

- ใน developer map ใช้ North-up และ R3/R4 เพื่อทำงานให้ถูก
- ใน player map **ไม่แสดงรหัสภายใน R1–R7 หรือ D1–D9**; ใช้ชื่อเมือง ด่านและลักษณะทางภูมิประเทศ
- อย่าอ้าง “ภาคอีสาน/ภาคเหนือ/ภาคกลาง/ภาคใต้” ใน in-world dialogue ในความหมายภาคประเทศไทยร่วมสมัย
- อนุญาตให้แผนที่โลกใหม่ไม่สมบูรณ์เพราะความรู้ยุคกลาง แต่ไม่ใช้การบิด/หมุนภูมิศาสตร์แบบจงใจหลอกผู้เล่นโดยไม่มีเหตุการณ์ในโลกอธิบาย
- แนวภูเขา/แม่น้ำจริงต้องพอเชื่อถือได้เมื่อผู้เล่นเปิดเผยทีหลัง จึงค่อยเกิด “อ๋อ!”

>
> “อย่าไว้ใจรอยเส้นบนแผนเก่ามากนัก ลำน้ำเปลี่ยนมาหลายชั่วคนแล้ว”
>
> “คนรุ่นปู่ย่าบอกว่ามีผู้สร้างสะพานยาวกว่าหุบเขา แต่ไม่มีใครรู้ว่าพวกเขาเรียกตัวเองว่าอะไร”

# 9. Spoiler Governance on a PUBLIC GitHub repository

**ข้อเท็จจริงสำคัญ:** Repository \`shanwinder/wanderer\` เป็น **public** ในวันที่ตรวจ นั่นหมายความว่า:

1. ข้อความใน \`docs/\`, branch, PR และ commit history **อ่านได้โดยบุคคลภายนอก** ถ้าตั้งใจเข้าไปค้น
2. การเปลี่ยนชื่อไฟล์/PR และลบข้อความใน README **ลดการสปอยล์แบบเห็นผ่าน ๆ ได้** แต่ **ไม่ลบ commit history/PR comment/archive ที่มีชื่อเดิม**
3. “DESIGNER ONLY” เป็น **สถานะเชิงกระบวนการ** ไม่ใช่สิทธิ์การเข้าถึงที่แท้จริงบน public GitHub
4. ถ้าต้องการซ่อนแม้คนที่เปิด GitHub ไปอ่าน ต้อง **ย้ายข้อมูล crosswalk และ reveal script ไป private repository หรือ private files นอก public repo** แล้วตั้งค่าไม่ export; ประวัติที่เคย public ไปแล้วไม่สามารถรับประกันให้หายจากการเข้าถึงย้อนหลังได้ด้วยการ rename อย่างเดียว
5. ห้ามสมมติว่าเอกสารใน \`docs/\` ถูก Godot export โดยอัตโนมัติหรือไม่ถูก export โดยอัตโนมัติโดยไม่ตรวจ preset/วิธี build จริง

**Recommended public hygiene:** root README ไม่ระบุประเทศไทยตรง ๆ, ใช้ชื่อไฟล์อธิบายโลกแบบกลาง ๆ, ใส่คำเตือน spoiler ใน docs index, และแยก source-of-truth เนื้อเรื่องลับออกจากชิ้นที่จัดส่งให้ผู้เล่นในระยะยาว

- [ ] ตรวจข้อความ title, credits, about, loading tips, splash screens, tutorial
- [ ] ตรวจ quest/item/achievement/tooltip/localization strings ที่ player รู้ก่อน gate
- [ ] ตรวจ screenshots, marketing captions, trailer subtitles, file names ที่ public เห็น
- [ ] ตรวจชื่อเมือง/แม่น้ำ/ที่ราบสูง — ไม่มี “โครา” “ภูพาน” และชื่อไทยจริงใน R0/R1
- [ ] ตรวจภาพ macro map ไม่เผยรูปร่างประเทศไทยครบ
- [ ] ตรวจบทพูด NPC ไม่เฉลยประเทศเดิมในช่วงต้น
- [ ] ตรวจเอกสาร designer-only ไม่ถูกบรรจุใน build โดยไม่ตั้งใจ
- [ ] ทุก Clue ของ R2–R4 มี origin, gating, rationale และไม่เฉลย Lore ที่ยัง OPEN
- [ ] playtest คนที่รู้ภูมิประเทศไทยดีและคนที่ไม่รู้ โดยถามว่า “เริ่มเดาตรงไหน, เพราะอะไร, ได้ข้อสรุปมั่นใจเมื่อไร”
- [ ] หากผู้เล่นเดาตั้งแต่ opening ให้ย้าย/ทำให้เบาะแสแรกคลุมเครือขึ้น ไม่ใช่ลบภูมิศาสตร์ทุกอย่าง
- [ ] หากผู้เล่นไม่เดาจนจบ อย่ายัด dialog เฉลยช่วงท้ายโดยอัตโนมัติ; เพิ่ม convergence ของหลักฐานที่เข้าใจได้

**No automated tests claimed:** รายการนี้เป็นเกณฑ์อนาคต ไม่ใช่ผลผ่าน QA ของเกมที่ยังไม่ได้ implement
