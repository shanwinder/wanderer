# 2. คำจำกัดความภาพรวมของภูมิประเทศ

1. **ตะวันตก (R3):** เข้าหาเมืองผ่านพื้นที่ไร่/ลำห้วยและทางบกที่มีการใช้งานสม่ำเสมอ
2. **ใจกลางเมือง:** ที่ดอนหรือชั้นดินที่รับน้ำดีกว่าแอ่งใกล้ห้วย มีลานเกวียนและตลาดใกล้ถนนหลักเพื่อไม่ขนหนักผ่านตรอกบ้าน
3. **เหนือเมือง:** แนวเนิน/สันป่าและหอเฝ้าทางสูง D9 ใช้ทัศนวิสัย ไม่ใช่ป้อมวิเศษ
4. **ตะวันออก (R4):** ที่สูงเปิดสู่ทางคาราวานและด่านช่องหิน (Route A)
5. **ตะวันออกเฉียงใต้/ทางต่ำ:** คันทางโลกเก่าที่เสียหายและปากอุโมงค์พัง (Route B); เป็นการเลี่ยงแนวด่านบางช่วง ไม่ใช่ทางลอดผ่านภูเขาอย่างปลอดภัย
6. **น้ำ:** ลำห้วยอยู่ห่างเขตช่าง/คอกสัตว์ มีแนวเก็บน้ำ/บ่อ D5 ในเขตที่ปลอดภัยกว่า; เส้นน้ำจากทิศเหนือไปทางตอนล่างเป็นสมมติฐานเชิงภาพ **ไม่ล็อกเป็น river model จริง**

**กฎแก้หลังตรวจ:** ไม่ให้ตลาดอยู่บนทางน้ำหลาก ไม่ให้น้ำเสียจาก D3/D4 ไหลเข้าบ่อโดยตรง และไม่ให้ทาง B เข้าถึงปากอุโมงค์โดยไม่ผ่านภูมิประเทศยากลำบาก

# 4. เส้นทางและการเชื่อมต่อ (City-to-Journey)

~~~text
R3 — ทางค้าฝั่งลุ่มน้ำ
   ↓
D1 ประตูตะวันตก — D2 ตลาดสองตรา — D3 ลานเกวียน — ประตูตะวันออก
                      │                  │
                   D7 ศูนย์ฯ          D4 ช่างเหล็ก
                      │                  │
                   D6 สภา ---------- D8 เรือนรักษา
                      ↑
                 D5 บ่อน้ำ / คลัง
                         ↑
                     D9 หอเฝ้า
                         |
       ทาง A จากประตูตะวันออก → ด่านช่องหิน → สะพานตอเก่า → ชุมชนพักแรม
       ทาง B จากทางแยกด้านตะวันออกเฉียงใต้ → คันทางพัง → ปากอุโมงค์พัง → หมุดสำรวจหาย
~~~

**ตรรกะเส้นทาง**
- คาราวานใช้ถนนหลักจนถึงด่านชั้นนอกเป็นปกติ
- ทาง B อาจเริ่มใกล้ทางออกเมืองแต่หักลงสู่คันทางด้านล่าง; **จุดแยกเป็นของจริงในภูมิประเทศ** ไม่ใช่ teleport node
- พื้นที่ภายในเมืองเดินด้วย Town UI ในอนาคต; **ไม่ต้อง implement world navigation เพื่อให้เชื่อมสองเส้นทางได้**
- route node ยืนยันได้เพียง adjacency/ลำดับตามเนื้อเรื่อง; ไม่มีตัวเลขชั่วโมงระยะทางจนกว่าจะกำหนด balance ของ M5

# 6. ชั้นข้อมูลสำหรับวาด (MAP-02B)

- **Layer G (terrain):** พื้นที่ดอน ลำน้ำ/แหล่งน้ำ สันเนิน แนวหิน และทางลาดฝั่ง R4
- **Layer S (settlement):** กลุ่มหลังคาไม้ ถนนสายหลัก ตลาด คลัง คอก ลานเกวียน หอเฝ้า
- **Layer R (routes):** เข้าจาก R3, ทาง A สีอำพัน/จุด, ทาง B สีเทาแตก/ขีด; ไม่มีความเร็วเดินทาง
- **Layer L (labels):** ตัวเลข D1–D9 + คำอธิบายใน legend; ลดการสะกดภาษาไทยผิดในภาพ generative
- **Layer O (old world):** ซากเสา/คันทาง, ปากอุโมงค์พัง — **ไม่ยืนยันชนิดอาคารเก่า** และไม่ใช้เทคโนโลยีปัจจุบันที่ยังสมบูรณ์
- **Layer X (secrets — designer only):** ความผิดปกติ/ข่าวลือและสถานที่ซึ่งยัง [OPEN] ไม่ปรากฏแผนที่ผู้เล่น

**สำคัญ:** ภาพในโลก (player atlas) อาจคลาดเคลื่อนหรือไม่มี D-label; ผังสำหรับนักออกแบบต้องมี D-label เพื่อใช้ตรวจภาพก่อนสร้าง UI

# 7. เรื่องเล่าที่ใช้ทดสอบเหตุผลของแผนที่

### A — พ่อค้าจากตะวันตก
เข้า D1 → ซื้อเสบียง D2 → ขนของลง D3 → ซ่อมล้อ D4 → ขอผ่านด่าน A. ถ้าทาง D2/D3 แยกไกลเกินไปผังควรแก้

### B — นักผจญภัยออกตามหาคนหาย
เข้าที่ D1 → รับข่าว D7 → พบญาติผู้สูญหาย D6/D8 → สำรวจทาง B. ต้องมีทาง B ออกจากเมืองโดยไม่ผ่าน Route A ทั้งหมด

### C — สมาชิกทีมบาดเจ็บหนัก
กลับมาทาง A หรือ B → ถึง D8 โดยไม่ต้องอ้อมลานเกวียนอย่างไม่สมเหตุผล → รายงานสมาคมที่ D7 ภายหลัง. จุดพักรักษาต้องมีทางเข้าถึงคนแบกผู้บาดเจ็บ

### D — ข่าวพลังจากดาราศิลา
คนที่ตลาด D2 พูดถึงผลึก, มลย์ (S08) ยื่นอุปกรณ์ที่ไม่ทราบคุณภาพ แต่ไม่มีอะไรยืนยันว่าเมืองมีเหมืองหรือของจริงจำนวนมาก. ความแปลกเป็น **เรื่องเล่า** ไม่ใช่พื้นที่เวท

# 8. Art Brief — สำหรับภาพ Concept Atlas MAP-02B

**ภาพที่ต้องการ:** แผนที่มุมบนของเมืองและขอบนอกแบบ *cartography/settlement plan* บนกระดาษเก่าที่มีงานหมึก-สีน้ำ ความรู้สึก late-medieval/early-modern post-post-apocalypse แบบ low magic

**องค์ประกอบบังคับ:**
1. North up; west = R3, east = R4
2. แหล่งน้ำอยู่ทางซ้ายของเมือง และเมืองตั้งที่ดอน; ที่สูง/หอ D9 ทางเหนือ
3. ถนนค้าหลักตะวันตก→ตะวันออกผ่าน D1, D2, D3 และประตูออกเมือง
4. D5 (น้ำ/ธัญ) อยู่นอกเขตคอกสัตว์และช่าง; D8 (เรือนรักษา) ไม่อยู่ชิดกองไฟ/โรงตีเหล็ก
5. Route A มุ่งไปด่านช่องหินฝั่งขวาบน มีทางเดินที่ดูใช้ได้
6. Route B หักลงขวาล่าง ผ่านคันทางผุเข้าสู่อุโมงค์เสียหาย มีคำเตือนทางทรุด
7. ลงเครื่องหมาย D1–D9 เป็น **ตัวเลขอ่านง่าย** และอธิบายใน legend แยกจากภาพ
8. มีจุดเริ่ม-จบพื้นที่ที่เห็นชัด โดยไม่สมมติมาตราส่วนหรือจำนวนชาวเมือง
9. สีหม่นลงและไม่มีแสงเวทมากจนผิดความหายากของดาราศิลา
10. **ภาพแสดงการจัดวาง** ไม่ใช่ภาพอ้างอิงก่อสร้างหรือแผนที่โลกจริง

**สิ่งที่ห้ามเติมโดยอัตโนมัติ:** มหาปราสาท กำแพงหินล้อมทั้งเมือง หอคอยสมัยใหม่ที่ยังใช้งาน หมู่บ้านเวททุกซอย ป้อมรูปดาวสมัยใหม่ แม่น้ำทะลุใจกลางโกดัง ทะเลติดเมือง อุกกาบาตปรากฏกลางเมือง
