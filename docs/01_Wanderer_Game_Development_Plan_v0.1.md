# 1. สาระสำคัญของโครงการ

**Wanderer** เป็นเกมผจญภัยเอาชีวิตรอดแบบ 2D Pixel Art ภาพภายนอกดูน่ารัก สดใส และเรียบง่าย แต่ระบบภายในโหดร้ายและไม่ปรานี

ผู้เล่นสร้างตัวละครของตนเองหนึ่งคน แล้วรับภารกิจจากศูนย์รวมนักผจญภัยในเมือง เดินทางร่วมกับ NPC อีกสามคนผ่านเส้นทางอันตราย ผู้เล่นควบคุมได้เฉพาะตัวละครของตนเอง ส่วน NPC มีเจตจำนง บุคลิก ความกลัว ความไว้ใจ และเหตุผลของตนเอง ผู้เล่นทำได้เพียงชี้นำ ไม่สามารถบังคับการกระทำของ NPC โดยตรงได้

สมาชิกทุกคนสามารถบาดเจ็บ ล้ม และเสียชีวิตถาวรได้ เมื่อตัวละครที่ผู้เล่นสร้างเสียชีวิต เกมจะปฏิบัติเสมือนว่าตัวละครนั้นตายจริง ผู้เล่นต้องสร้างหรือเลือกตัวละครอื่นเพื่อดำเนินโลกเดิมต่อไป อย่างไรก็ตาม ภายในโลกจะมีเบาะแสที่บอกเป็นนัยว่า ความตายอาจไม่ใช่จุดจบเสมอไป โดยผู้เล่นต้องค้นพบวิธีคืนชีพด้วยตนเองผ่านการเล่นและการตีความเรื่องราว

> **ประโยคแกนกลางของเกม**  
> “ผู้เล่นควบคุมได้เพียงตัวเอง แต่ชีวิตของผู้เล่นอาจขึ้นอยู่กับการตัดสินใจของคนอื่น”

# 5. Setting ของโลก

## 5.1 ยุคสมัย

**[LOCKED]**

โลกของเกมอยู่ในช่วง **ปลายยุคกลางถึงต้นยุคใหม่** แต่เกิดขึ้นหลายพันปีหลังอารยธรรมยุคปัจจุบันของเราล่มสลายไปแล้ว

เกมอยู่ในแนว **Post-post-apocalypse** กล่าวคือ หายนะผ่านมานานมากจนมนุษย์ในยุคเกมไม่รู้สึกว่าตนอยู่ในโลกหลังหายนะ โลกใหม่คือโลกปกติของพวกเขา

มนุษย์ไม่ได้จำเป็นต้องวิวัฒนาการทางชีววิทยาใหม่ แต่เกิดการเปลี่ยนแปลงด้าน:

- ภาษา
- วัฒนธรรม
- ความเชื่อ
- โครงสร้างการปกครอง
- เทคโนโลยี
- ความรู้ทางการแพทย์และวิทยาศาสตร์
- การตีความซากอารยธรรมเดิม

## 5.2 เหตุผลที่เทคโนโลยีกลับสู่ระดับปลายยุคกลาง

**[LOCKED]**

เทคโนโลยีสมัยใหม่ต้องอาศัยระบบที่ซับซ้อน เช่น:

- โรงไฟฟ้า
- โรงงานผลิตชิ้นส่วน
- เหมืองและโรงถลุงขนาดใหญ่
- เครือข่ายการขนส่ง
- ระบบข้อมูล
- สถาบันการศึกษา
- รัฐและองค์กรที่รักษาความรู้ต่อเนื่อง

หลังระบบเหล่านี้ล่มสลาย มนุษย์จึงสร้างสังคมใหม่ด้วยสิ่งที่ผลิตและซ่อมแซมได้ในท้องถิ่น เช่น:

- ดาบ หอก ขวาน ธนู หน้าไม้
- เกราะผ้า หนัง และโลหะ
- เรือใบ เกวียน และม้า
- กระดาษ แผนที่ และแท่นพิมพ์พื้นฐาน
- สมุนไพร การเย็บแผล และการผ่าตัดพื้นฐาน
- กลไกนาฬิกาและดินปืนระยะแรก

## 5.3 ความหลากหลายทางวัฒนธรรม

**[LOCKED]**

โลกมีอารยธรรมใหม่หลายกลุ่ม ซึ่งได้รับแรงบันดาลใจจาก:

- จีน
- ญี่ปุ่น
- อินเดียและเอเชียใต้
- ยุโรป
- ตะวันออกกลางและแอฟริกาเหนือ
- เอเชียตะวันออกเฉียงใต้

วัฒนธรรมเหล่านี้ไม่ใช่ประเทศเดิมที่อยู่รอดมาตรง ๆ แต่เป็นอารยธรรมใหม่ที่พัฒนาขึ้นจาก:

- สภาพภูมิศาสตร์
- ทรัพยากร
- กลุ่มผู้รอดชีวิต
- ซากโครงสร้างเดิม
- การค้าและการอพยพ
- ความรู้ที่เหลือรอดแบบไม่สมบูรณ์

ตัวอย่างพื้นที่:

- ลุ่มแม่น้ำและเขื่อนเก่า → สังคมเกษตรและระบบราชการ
- หมู่เกาะและฐานทัพเรือเก่า → วัฒนธรรมทางทะเลและตระกูลนักรบ
- เมืองท่าเขตร้อน → นครการค้าแบบเอเชียตะวันออกเฉียงใต้
- เขตชลประทานและศูนย์การศึกษาเดิม → เมืองวิชาการและศาสนา
- พื้นที่แห้งแล้งรอบท่อส่งหรือโรงกลั่น → เมืองโอเอซิสและคาราวาน
- พื้นที่เมืองเก่าและป้อมบนที่ราบหนาว → รัฐศักดินาและสมาคมช่าง

## 5.4 การพบร่องรอยโลกเก่า

**[LOCKED]**

เกมจะไม่บอกตรง ๆ ว่าสิ่งที่พบคืออะไร ผู้เล่นเห็นผ่านสายตาของคนในโลกใหม่ เช่น:

- ทางหลวงถูกเรียกว่า “ทางของสัตว์เหล็ก”
- สถานีรถไฟใต้ดินถูกเรียกว่า “อุโมงค์ของกษัตริย์ผู้ไม่เห็นแสง”
- ป้ายเตือนรังสีถูกตีความเป็นสัญลักษณ์ศักดิ์สิทธิ์
- เสาไฟฟ้าหรือเสาสัญญาณถูกเรียกว่า “หอคอยเรียกสายฟ้า”
- เครื่องกรองน้ำถูกบูชาเป็นบ่อน้ำศักดิ์สิทธิ์
- สัญลักษณ์ปฐมพยาบาลกลายเป็นตราของกลุ่มผู้รักษา
- เครื่องหมายรีไซเคิลกลายเป็นสัญลักษณ์ของวัฏจักรชีวิต

### กฎการเล่าเรื่องโลกเก่า

1. คนในเกมไม่ใช้คำศัพท์สมัยปัจจุบันโดยตรง
2. ซากอาคารต้องเสื่อมสภาพ ถูกฝัง หรือถูกนำวัสดุไปใช้แล้ว
3. ทุกสิ่งควรมีคำอธิบายได้มากกว่าหนึ่งแบบ
4. เทคโนโลยีเก่าต้องหายาก เสียหาย และไม่สามารถผลิตซ้ำง่าย
5. โลกใหม่ต้องสำคัญกว่าโลกเก่า
6. เกมไม่ควรเฉลยสาเหตุการล่มสลายเร็วเกินไป
7. เหตุแห่งการล่มสลายอาจเป็นหลายวิกฤตต่อเนื่อง ไม่ใช่เหตุเดียว

## 5.5 เวทมนตร์

**[PROTOTYPE]**

โลกควรมีลักษณะ Low Fantasy:

- เครื่องราง
- คำสาป
- พิธีกรรม
- สิ่งมีชีวิตผิดธรรมชาติ
- สถานที่ที่มีกฎประหลาด
- การคืนชีพที่เป็นเรื่องต้องห้ามหรือข่าวลือ

ยังไม่กำหนดชัดว่าเวทมนตร์เป็นสิ่งเหนือธรรมชาติจริง หรือเป็นผลจากเทคโนโลยีและชีววิทยาเก่าบางส่วน

# 6. บทบาทของผู้เล่น

## 6.1 อาชีพในภาพรวม

**[LOCKED]**

รางวัลจากเควสประกอบด้วย:

- เงิน
- ไอเทม
- ค่าประสบการณ์
- ชื่อเสียงส่วนตัว
- ความน่าเชื่อถือของใบอนุญาตนักผจญภัย
- การเปิดเส้นทาง เมือง ข่าวลือ หรือข้อมูลใหม่

## 6.2 ศูนย์รวมนักผจญภัย

**[LOCKED]**

ศูนย์รวมนักผจญภัยทำหน้าที่เป็น:

- กระดานเควส
- จุดรับสมัครหรือชักชวน NPC
- จุดบันทึกชื่อเสียงและใบอนุญาต
- แหล่งข่าวสารเส้นทาง
- จุดเชื่อมความก้าวหน้าระดับไฟล์เซฟ

ศูนย์อาจเป็นเครือข่ายของสมาคมพ่อค้า สถานีเดินทาง และสำนักงานรับงานที่ใช้มาตรฐานร่วมกัน ไม่จำเป็นต้องเป็นองค์กรเดียวที่มีอำนาจทั่วโลก

# 7. การสร้างตัวละคร

## 7.1 ตัวเลือกเริ่มต้น

**[LOCKED]**

ผู้เล่นสร้างตัวละครได้ทั้งชายและหญิง

ยังไม่มีการเลือก Class ตอนสร้าง

ตัวเลือกเบื้องต้น:

- ชื่อ
- เพศ
- รูปลักษณ์
- ทรงผม
- สีผม
- สีเสื้อ
- ภูมิหลัง
- เหตุผลที่ออกเดินทาง
- คุณค่าที่ให้ความสำคัญ
- ความถนัดเริ่มต้นเล็กน้อย

## 7.2 คำถามภูมิหลัง

**[PROTOTYPE]**

ใช้คำถามประมาณ 3 ข้อ:

### คำถามที่ 1: เหตุใดคุณจึงออกเดินทาง

ตัวอย่าง:

- หาเงินใช้หนี้
- ตามหาคนที่หายไป
- หนีจากอดีต
- ต้องการเห็นโลกและซากโบราณ

### คำถามที่ 2: คุณเติบโตมาจากที่ใด

ตัวอย่าง:

- เมืองท่า
- หมู่บ้านป่าเขา
- นครการค้า
- ชุมชนใกล้ซากโบราณ

### คำถามที่ 3: สิ่งใดสำคัญที่สุดสำหรับคุณ

ตัวอย่าง:

- ชีวิตของผู้ร่วมทาง
- ชื่อเสียงและเกียรติ
- ความมั่งคั่ง
- อิสระของตนเอง

คำตอบมีผลต่อ:

- จุดเริ่มต้น
- ความถนัด
- ไอเทมเริ่มต้น

# 13. Level, Class และการเติบโต

## 13.1 Level

**[PROTOTYPE]**

ควรมี Level เพื่อให้ผู้เล่นรู้สึกถึงความก้าวหน้าและมูลค่าของตัวละคร

ข้อเสนอ:

- Level 1–20
- เพิ่ม HP เล็กน้อย
- เปิดช่อง Passive
- เพิ่มแต้มพัฒนาบางช่วง
- ไม่เพิ่มพลังแบบทวีคูณ
- ตัวละคร Level สูงยังตายได้จากความผิดพลาด บาดแผล พิษ หรือการถูกทอดทิ้ง

XP ควรมาจาก:

- ทำเควส
- ไปถึงจุดหมาย
- สำรวจ
- รอดจากเหตุการณ์
- ช่วยสมาชิก
- ใช้ทักษะแก้ปัญหา
- เรียนรู้สิ่งใหม่
- ต่อสู้เมื่อจำเป็น

ไม่ควรให้ XP จากการฆ่าเป็นหลัก

## 13.2 Class

**[LOCKED]**

ไม่มีการเลือก Class ตอนสร้างตัวละคร

Class เกิดจาก:

- ความชำนาญ
- รูปแบบการกระทำ
- บทบาทที่ทำซ้ำ
- เหตุการณ์สำคัญ
- การยอมรับจากผู้อื่น

ตัวอย่าง:

- ใช้ดาบและต่อสู้แนวหน้า → นักรบ
- ใช้ดาบปกป้องเพื่อน → ผู้พิทักษ์
- ใช้ธนู วางกับดัก และตามรอย → นักล่า
- รักษาและช่วยผู้บาดเจ็บ → ผู้รักษา
- สำรวจและปลดกับดัก → นักสำรวจ

Class ไม่ล็อกอุปกรณ์ ตัวละครยังใช้อาวุธหรือเครื่องมือประเภทอื่นได้

Class ให้:

- Passive
- การกระทำเฉพาะ
- ตัวเลือกเหตุการณ์
- การยอมรับทางสังคม
- ชื่อเรียกที่สะท้อนชีวิตที่ผ่านมา

## 13.3 ความก้าวหน้าสองระดับ

**[LOCKED]**

### ระดับตัวละคร

- Level
- Class
- ความชำนาญ
- อุปกรณ์
- ความสัมพันธ์
- บาดแผล
- ชื่อเสียงส่วนตัว

เมื่อตาย สิ่งเหล่านี้สูญเสียพร้อมตัวละคร

### ระดับไฟล์เซฟ / ศูนย์นักผจญภัย

- ระดับใบอนุญาต
- เมืองและเส้นทาง
- ข่าวสาร
- แผนที่
- ของที่ฝากไว้
- บันทึกผู้ตาย
- ข้อมูลศัตรู
- ความรู้เกี่ยวกับอารยธรรมเก่า

สิ่งเหล่านี้ยังคงอยู่หลังตัวละครตาย

# 14. ระบบล้ม ความตาย และศพ

## 14.1 การล้ม

**[LOCKED]**

เมื่อ HP เหลือ 0 ตัวละครเข้าสู่สถานะล้มก่อนตาย

ขณะล้ม:

- ไม่สามารถต่อสู้ตามปกติ
- อาจเลือดออก
- ถูกโจมตีซ้ำได้
- เพื่อนสามารถช่วย ลาก หรือแบกได้
- มีเวลาจำกัดก่อนเสียชีวิต

ตัวละครผู้เล่นอาจมีเวลาขณะล้มนานกว่า NPC เล็กน้อย เพื่อให้ตายยากกว่าโดยไม่ต้องมี HP สูงผิดธรรมชาติ

## 14.2 การตาย

**[LOCKED]**

ทุกคนตายถาวรได้

เมื่อตัวละครผู้เล่นตาย:

- เกมไม่จบทันที
- NPC ที่เหลือยังตัดสินใจต่อ
- NPC อาจต่อสู้ หนี ช่วยคนอื่น หรือแบกศพ

## 14.3 การนำศพกลับ

# 22. ขอบเขต Prototype แรก

## 22.1 เป้าหมาย

**[LOCKED]**

พิสูจน์คำถามเดียว:

> “การต่อสู้ที่ผู้เล่นควบคุมเพียงตัวเอง และ NPC อีกสามคนตัดสินใจเอง สนุกหรือไม่”

## 22.2 เนื้อหา

**[PROTOTYPE]**

- หน้าต่อสู้ 1 หน้า
- Player 1 คน
- NPC 3 คน
- Enemy 2 คน
- ใช้สี่เหลี่ยมหรือ Label แทนตัวละคร
- HP
- Attack
- Defense
- Speed
- สถานะ Alive / Down / Dead
- Action: Attack / Defend / Help / Retreat
- Guidance: Attack / Defend / Help / Retreat
- NPC AI แบบง่าย
- ระบบล้ม
- ระบบช่วย
- ระบบตาย
- ระบบหนี
- หน้าสรุปผล

## 22.3 AI ขั้นต้น

เริ่มจาก 3 ค่า:

- Courage
- Compassion
- Discipline

กติกาตัวอย่าง:

- HP ต่ำ + Courage ต่ำ → Defend หรือ Retreat
- เพื่อน HP ต่ำ + Compassion สูง → Help
- Guidance ตรงกับสถานการณ์ + Discipline สูง → ทำตาม
- ไม่มีเหตุการณ์สำคัญ → Attack

หลัง Prototype ทำงานจึงเพิ่ม:

- Self-preservation
- Ambition
- Trust
- Injury
- Fear

## 22.4 เงื่อนไขความสำเร็จ

Prototype ถือว่าผ่านเมื่อ:

1. การต่อสู้เริ่มและจบได้
2. Player เลือกการกระทำได้
3. NPC เลือกเองได้
4. NPC อาจทำตามหรือฝ่าฝืนคำชี้นำ
5. ระบบบอกเหตุผลการตัดสินใจ
6. ตัวละครล้มและตายได้
7. NPC ช่วยหรือทอดทิ้งได้
8. ทีมถอยได้
9. ผู้เล่นรู้สึกว่าตนต้องเรียนรู้ NPC

4. จำนวน Class ในเกมเต็ม
5. Class สามารถเปลี่ยนหรือมีหลายบทบาทได้เพียงใด
6. สาเหตุการล่มสลายที่แท้จริง
7. เวทมนตร์เป็นสิ่งเหนือธรรมชาติหรือเทคโนโลยีที่ถูกตีความใหม่
8. ราคาของการคืนชีพ
9. ความเสียหายของศพมีผลเพียงใด
10. จุดจบของเควสหลัก
11. จำนวนภูมิภาคในเกมเต็ม
12. ระบบภาษาและความต่างทางวัฒนธรรมจะมีผลระดับใด
13. Player จะมีข้อได้เปรียบในการล้มและรอดมากกว่า NPC เท่าไร
14. ระบบ Save จะป้องกัน Save Scumming ระดับใด
15. เกมจะมีโหมดความยากหรือไม่

# 28. กฎการทำงานของโครงการ

1. ระบบมาก่อน Asset
2. Prototype มาก่อนเกมเต็ม
3. Placeholder ใช้ได้นานเท่าที่จำเป็น
4. ไม่เพิ่มระบบก่อนของเดิมเล่นได้
5. Commit Git ทุกครั้งที่จบงานสำคัญ
6. ทำทีละ Milestone
7. ทุก Feature ใหม่ต้องตอบว่าเพิ่มความสนุกของแกนหลักหรือไม่
8. หากไม่จำเป็นต่อ Prototype ให้ย้ายไป Backlog
9. ทดสอบด้วยผู้เล่นจริงก่อนลงทุนกับงานภาพ
10. ความสำเร็จระยะแรกคือ “เล่นได้และน่าสนใจ” ไม่ใช่ “สวยและครบ”
