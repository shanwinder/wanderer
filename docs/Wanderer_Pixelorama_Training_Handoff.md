# Wanderer — Pixelorama / JRPG Pixel Sprite Training Handoff

## 1. เป้าหมายของการฝึก

ผู้ใช้ต้องการฝึกวาด **Pixel Sprite แนว JRPG / Octopath-inspired** ใน Pixelorama เพื่อใช้กับเกมต้นแบบ **Wanderer**

เป้าหมายไม่ใช่การเลียนแบบกระบวนการผลิตของ Octopath Traveler ทุกขั้น แต่คือ:

- มือใหม่ทำตามได้จริง
- ได้ผลลัพธ์เร็ว
- ใช้ในเกมได้
- ตัวละครอ่านง่ายเมื่อมีขนาดเล็ก
- มีรายละเอียดแฟนตาซีแบบ JRPG
- ใช้ Pixel Cluster ที่ชัด ไม่โรยพิกเซลแบบสุ่ม
- ใช้พาเลตจำกัดและมีแสง–เงา–ไฮไลต์ที่เป็นระบบ

## 3. ความเข้าใจที่ยืนยันแล้ว

### 3.1 กระบวนการของ Octopath จริง

ไม่ควรกล่าวว่าขั้นตอนที่ฝึกกันเป็นขั้นตอนผลิตจริงของทีม Octopath แบบยืนยันแล้ว

สิ่งที่ทราบในเชิงหลักการ:

- มีภาพออกแบบตัวละครความละเอียดสูงก่อน
- แล้วสร้างสไปรต์ขนาดเล็กขึ้นใหม่โดยตั้งใจ
- ไม่ใช่เพียงวาดภาพ HD แล้วลดขนาดอัตโนมัติ
- สไปรต์มีการเก็บแก้พิกเซลด้วยมือ
- แอนิเมชันอาจใช้เครื่องมือช่วยบิดชิ้นส่วน แล้วกลับมาเก็บพิกเซลใหม่
- ความเป็น HD-2D เกิดจากสไปรต์ 2D ร่วมกับฉาก 3D แสง เงา Bloom และ Depth of Field

### 3.2 Workflow ที่เหมาะกับผู้ใช้

```text
ภาพออกแบบ / ภาพอ้างอิง
→ Guide และสัดส่วน
→ Blockout / Color Block โดยตรง
→ Base Colors
→ Shadows + Highlights
→ Details / Cleanup
→ ตรวจที่ขนาดใช้งานจริง
```

**Silhouette สีเดียวไม่จำเป็นต้องเป็นขั้นแยกทุกครั้ง**

ใช้ silhouette เพียงเพื่อตรวจ:

- ขอบนอกของทรงผม
- รูปทรงรวมของไหล่/ผ้าคลุม
- ชายผ้าที่ยื่น
- ช่องระหว่างขา
- รูปทรงรองเท้าและอาวุธ

Silhouette สีเดียวไม่สามารถแสดงชั้นเสื้อ แขน เอว และรายละเอียดภายในที่ติดกันได้ จึงไม่ควรบังคับให้มันทำหน้าที่แทน Color Block

## 5. ข้อผิดพลาดที่ไม่ควรทำซ้ำ

- อย่าเริ่มด้วยหุ่นคนธรรมดาสูงเพรียว ถ้าเป้าหมายคือ Octopath-inspired
- อย่าบังคับให้ silhouette สีเดียวแยกส่วนภายในที่ติดกัน
- อย่าให้คำแนะนำซ้ำในสิ่งที่ผู้ใช้ทำไปแล้ว เช่น สั่งลงเงาอีกทั้งที่ภาพมีเงาและไฮไลต์แล้ว
- ต้องตรวจภาพล่าสุดอย่างละเอียดก่อนสั่งขั้นถัดไป
- อย่าให้ Guide สูงเกินจนตัวละครดูเป็นคนจริงย่อส่วน
- อย่าใช้ outline ดำล้อมทุกชิ้นโดยอัตโนมัติ
- อย่าใส่รายละเอียดจุกจิกทั้งหมดจากภาพอ้างอิงลงในสไปรต์
- ควรเก็บเฉพาะจุดจำหลักของตัวละคร

## 6. ตัวเอก Wanderer — ดีไซน์ล่าสุด

### แนวคิด

นักผจญภัยหนุ่มพเนจร ผู้รับเควสจากกิลด์ บุคลิกสุขุม เงียบแต่ไม่เย็นชา คล่องตัว และดูพึ่งพาได้

### รูปร่างและใบหน้า

- ชาย อายุภาพลักษณ์ประมาณ 17–22 ปี
- รูปร่างสูงโปร่งและคล่องตัว
- ใบหน้าเรียว
- สีหน้าสงบ สุขุม
- ผมยุ่งเล็กน้อย ความยาวปานกลาง
- หน้าม้าปัดเฉียง
- ปลายผมแตกเป็นช่อ
- สีผมดำอมเทาหรือน้ำตาลเข้มหม่น

### เครื่องแต่งกาย

- เสื้อชั้นในสีเทาอ่อนหรือครีมหม่น
- ผ้าคลุมคอ/ผ้าคลุมไหล่สั้นสีกรมท่าหม่น
- เสื้อคลุมสั้นเปิดด้านหน้า
- ชายผ้าหรือโค้ทสั้นยาวระดับต้นขา
- กางเกงเข้ารูปสีดำอมฟ้าหรือเทาเข้ม
- ถุงมือหรือปลอกแขนหนัง
- บูตหนังสูง
- เข็มขัดหลักและสายคาดเฉียงพาดลำตัว
- จี้หรือเหรียญตรากิลด์เล็กบริเวณอก
- กระเป๋าหนังขนาดเล็กที่เอว

### อาวุธ

- ดาบเดี่ยวทรงเพรียวหรือคาตานะสั้น
- ด้ามพันผ้า
- การ์ดเรียบ
- ฝักดาบอยู่ด้านข้างหรือเอียงเล็กน้อย
- โทนดำ/น้ำตาลเข้ม/เงินหม่น
- รายละเอียดทองหม่นหรือฟ้าอมเงินเล็กน้อย

### จุดจำสำคัญเมื่อแปลงเป็นสไปรต์

1. ผมยุ่งปัดเฉียง
2. ผ้าคลุมไหล่สีน้ำเงินเข้ม
3. เสื้อในสีอ่อน
4. สายคาดเฉียงพาดลำตัว
5. เข็มขัด
6. ถุงมือหนัง
7. บูตสูง
8. ดาบและฝัก

## 7. ภาพอ้างอิงที่สร้างแล้ว

มีภาพอ้างอิง 2 แบบที่ควรนำไปแนบในแชตใหม่:

### A. ภาพตัวละครรายละเอียดสูง

- ภาพตัวเอกเต็มตัว
- ชุดกรมท่า–เทา–น้ำตาล
- ผ้าคลุมสั้น
- สายคาดเฉียง
- ดาบคาตานะพร้อมฝัก
- ใช้เป็น Canonical Concept Reference

### B. ภาพแปลงเป็น Pixel Art

- ภาพตัวละครในรูปแบบ Pixel Art
- ใช้ดูการลดรายละเอียด
- ยังมีรายละเอียดมากและสัดส่วนสูงกว่าสไปรต์ Octopath จริง
- ใช้เป็น “ภาพช่วยอ่านชุด” ไม่ใช่สัดส่วนสุดท้าย

เมื่อเริ่มแชตใหม่ ให้แนบภาพ A และ B อีกครั้ง

## 8. Canvas และ Guide ล่าสุด

### Canvas

```text
64 × 96 px
พิกัดเริ่มจากมุมซ้ายบน:
(0,0)

ช่วงพิกัดจริง:
x = 0–63
y = 0–95
```

### Guide เดิมที่ถูกปฏิเสธ

กรอบสูงประมาณ 60–64 px ทำให้ตัวละครดูสูงและขายาวเกินไป ไม่ใกล้ Octopath-inspired

### Guide ใหม่ที่กระชับกว่า

กรอบตัวละคร:

```text
ซ้าย   x = 20
ขวา    x = 43
บน     y = 16
ล่าง   y = 59
```

พื้นที่รวม:

```text
กว้าง 24 px
สูง 44 px
```

แกนกลาง:

```text
x = 32
จาก y = 16 ถึง y = 59
```

เส้นแบ่งสัดส่วนแนวนอน:

```text
y = 16  ยอดผม
y = 26  ปลายคาง
y = 30  แนวไหล่
y = 36  อก / ลำตัวบน
y = 41  เอว / เข็มขัด
y = 45  สะโพก / จุดเริ่มขา
y = 51  แนวหัวเข่า
y = 55  ขอบบนบูต
y = 59  พื้นรองเท้า
```

หมายเหตุ:

- Guide ชุดนี้ยังเป็นจุดเริ่มต้น ไม่ใช่สัดส่วนตายตัว
- ผู้ใช้ต้องการให้วัดจาก `(0,0)` มุมซ้ายบนเสมอ
- ตัวละครแนว Octopath-inspired ควรหัวใหญ่ ลำตัวสั้น และขาสั้นกว่าคนจริง
- ดาบ ผ้าคลุม และปอยผมสามารถเลยกรอบได้
- ตัวละครควรอยู่ประมาณ 40–46 px สูงในช่วงฝึก

## 9. งานถัดไปในแชตใหม่

### งานหลัก

**แตก Guide ใหม่เป็นจำนวนพิกเซลจริงสำหรับตัวเอก**

ต้องกำหนด:

- หัวกว้าง/สูงกี่ px
- ใบหน้ากว้าง/สูงกี่ px
- ผมยื่นออกแต่ละด้านกี่ px
- ไหล่กว้างกี่ px
- ลำตัวบนกว้าง/สูงกี่ px
- เอวกว้างกี่ px
- สะโพกกว้างกี่ px
- ขาแต่ละข้างกว้าง/สูงกี่ px
- ช่องกลางขากี่ px
- บูตกว้าง/สูงกี่ px
- จุดวางสายคาดเฉียง
- จุดวางผ้าคลุม
- ตำแหน่งด้ามดาบและฝักดาบ
- ทุกตำแหน่งต้องอ้างอิงพิกัดจากมุมซ้ายบน `(0,0)`

### วิธีสอนที่ต้องการ

- สอนทีละช่วง
- อย่าสั่งหลายขั้นพร้อมกันเกินไป
- ตรวจภาพล่าสุดก่อนแนะนำ
- ระบุพิกัดชัดเจน
- อธิบายว่าพิกัดนั้นมีหน้าที่อะไร
- ไม่บังคับให้สมมาตรสมบูรณ์
- เน้นให้ผู้ใช้วาดเอง ไม่ใช่คัดลอกภาพสำเร็จทั้งหมด

## 10. ข้อความพร้อมใช้สำหรับเริ่มแชตใหม่

คัดลอกข้อความต่อไปนี้ไปเริ่มแชตใหม่ พร้อมแนบภาพตัวเอกความละเอียดสูงและภาพ Pixel Art ที่สร้างไว้:

```text
เรากำลังฝึกวาด Pixel Sprite แนว JRPG / Octopath-inspired ใน Pixelorama สำหรับเกม Wanderer

ผมผ่านแบบฝึก Color Block, Base Colors, Shadows, Highlights และ Details มาแล้ว รอบนี้จะวาดตัวเอกจริงจากภาพอ้างอิงที่แนบ

Canvas คือ 64×96 px และ Pixelorama ใช้มุมซ้ายบนเป็น (0,0)

Guide ล่าสุดที่ตกลงไว้:
- กรอบ: x=20..43, y=16..59
- แกนกลาง: x=32
- เส้นแนวนอน: y=16, 26, 30, 36, 41, 45, 51, 55, 59

เป้าหมายคือสไปรต์สูงประมาณ 40–46 px หัวใหญ่ ลำตัวและขากระชับ ไม่สูงเพรียวแบบคนจริง

ช่วยเริ่มต่อจาก “แตก Guide เป็นจำนวนพิกเซลจริง” สำหรับหัว ผม ใบหน้า ไหล่ ลำตัว เอว สะโพก ขา บูต ผ้าคลุม สายคาดเฉียง ด้ามดาบ และฝักดาบ โดยอ้างอิงพิกัดจาก (0,0) ทุกครั้ง

สอนทีละช่วงและตรวจภาพที่ผมส่งก่อนขยับไปขั้นถัดไป อย่าสั่งหลายขั้นพร้อมกัน และอย่าบังคับใช้ silhouette สีเดียวเป็นขั้นแยก ถ้า Color Block โดยตรงเหมาะกว่า
```
