# 1. คำโปรยหน้าจอเริ่มเกม (R0)

โลกมิได้สิ้นสุดลงเมื่อเมืองสุดท้ายล่มสลาย

ผู้คนสร้างบ้านบนรากฐานที่ไม่รู้ชื่อ ปลูกพืชตามฤดูน้ำ และเปิดเส้นทางผ่านดินแดนที่เคยมีใครสักคนเดินทางมาก่อน

คุณมาถึงนครประตูหินพร้อมสัมภาระเพียงเท่าที่แบกไหว ที่นี่ผู้คนหาเลี้ยงชีพจากเกวียน ประตู และข่าวที่ไม่มีใครรับรองได้ทั้งหมด

บางเส้นทางมีคนดูแล บางเส้นทางไม่มีใครกล้ารับผิดชอบ

**ส่วนเพื่อนร่วมทางของคุณ จะยอมไปด้วยกันไกลแค่ไหน — คุณไม่มีทางสั่งแทนพวกเขาได้**

## 1.1 หลีกเลี่ยง

ห้ามใส่คำว่า “ประเทศไทย”, “โคราช”, ชื่อจังหวัด/แม่น้ำยุคปัจจุบัน, “เราทุกคนเคยเป็นคนไทย”, อุกกาบาตทำลายประเทศ, ภาพถ่ายเมืองจริง หรือคำใบ้ที่ระบุตำแหน่งประเทศอย่างแน่นอนในข้อความเปิดเกม

# 2. ฉากเข้าเมืองครั้งแรก (short in-game beat)

### Image prompt / mood (for later art only)
ลานเกวียนแห้งกว่าข้างทาง มีคนผูกสัตว์บรรทุก รถล้อไม้และร่มผ้าปะ ตึกเป็นไม้/หินธรรมดา เก็บซากคอนกรีตเป็นฐานบางจุด ไม่โชว์ landmark โลกปัจจุบัน

### ฉากข้อความตัวอย่าง

**เสมียนด่าน:** “เข้าเมืองได้ แต่เขียนชื่อไว้ด้วย เผื่อมีใครมาตามหา”

**ผู้ลากเกวียน:** “ถ้าจะออกไปทางประตูบน ให้ถามราคาค่าผ่านก่อนฟ้ามืด”

**หญิงถือผ้าพันแผล:** “อย่าฟังคนที่บอกว่าทางเก่าปลอดภัย ฉันรักษาคนที่กลับมาจากมันอยู่ทุกฤดู”

ตัวละครผู้เล่นมีตัวเลือกถามสั้น ๆ:
- “ทางไหนมีคนดูแล?”
- “มีงานให้ทำไหม?”
- “ถ้าเพื่อนร่วมทางไม่อยากไปด้วยล่ะ?”

แต่ละคำตอบพาผู้เล่นไป **ข่าว**, **ศูนย์รับงาน**, หรือ **ระบบคำชี้นำ** ตาม Milestone ที่มีจริงในอนาคต; ณ ตอนนี้ยังเป็น mock-up

# 4. เควสเปิดโลกช่วงแรก (R0)

## Q1 — จดหมายข้ามประตู

**ประกาศ:** “ชุมชนพักแรมปลายทางกำลังรอข่าวขนส่งสินค้า เราต้องการคนนำคำตอบกลับมาอย่างปลอดภัย ค่าจ้างชำระเมื่อมีหลักฐานส่งถึงมือผู้รับ”

**สิ่งที่ผู้เล่นทราบ:** งานส่งสาร, มีทางด่านและรอยทางเก่า; ข้อมูลจากคนสองกลุ่มไม่ตรงกัน

**Player-safe objective:** “ส่งข่าวถึงผู้รับ แล้วกลับมารายงานสภาพทาง”

**NPC prompt:** “คีรินไม่เชื่อคำรับรองของพ่อค้าที่เพิ่งมาถึง และเสนอให้เลือกทางมีด่าน”

**ห้าม:** ข้อความว่าด่านนี้อยู่ที่ถนน/เขตจังหวัดใดในโลกเก่า

## Q2 — ร่องรอยของคนไม่กลับ

**ประกาศ:** “ครอบครัวผู้เดินทางต้องการหลักฐานจากขบวนที่หายไป ไม่ต้องมีคำสาบานว่าจะพาทุกคนกลับ ขอเพียงอย่าแต่งเรื่องกับคนที่ยังรออยู่”

**Player-safe objective:** “ค้นข่าวที่ตรวจสอบได้ และพาคนเจ็บกลับหากทำได้”

**NPC prompt:** “เมียร่าอยากช่วยคนที่ยังรอด รอนโดอยากรักษาสัญญากับผู้เดินเกวียน ส่วนลาเวนเตือนให้เตรียมเสบียงสำหรับการถอย”

**ห้าม:** สัญลักษณ์ราชการยุคปัจจุบันบนหีบคาราวานตั้งแต่ฉากนี้

## Q3 — แสงในรอยทาง

**ประกาศ:** “มีผู้ได้ยินเสียงและเห็นแสงแปลกใกล้ทางที่ปิด ผู้ดูแลทางต้องการข้อมูล ไม่ใช่คำทำนาย”

**Player-safe objective:** “สำรวจจากระยะที่ปลอดภัย บันทึกสิ่งที่เห็น และแยกสิ่งยืนยันได้ออกจากคำเล่า”

**NPC prompt:** “อารินเชื่อว่าควรสำรวจ คอลอยากตรวจความมั่นคงของทางก่อน คีรินเกรงว่าคนไม่กลับจะเพิ่มอีก”

**Lore guardrail:** สามารถอธิบายข่าวแสงด้วยเหตุธรรมดาหรือยังไม่เฉลย; ไม่เปิดตำแหน่งจริงของดาราศิลาหรือความจริงหายนะ

# 7. Player route map — textual brief (R0)

~~~text
          ด่านบนเขา
             |
        ทางประตูบน
             |
นครประตูหิน — ทางค้าจากตะวันตก
             |
         รอยทางเก่า
             |
        ปากทางทรุด
~~~

**นี่เป็นผังความสัมพันธ์ ไม่ใช่รูปแผนที่จริง**: ไม่ให้ผู้เล่นเห็น Atlas 7 ภูมิภาคหรือรูปร่างแนวพรมแดนรัฐยุคก่อน; แผนที่เปิดเฉพาะเมื่อข่าวมีที่มาและผู้เล่นสำรวจ

## 7.1 Visual controls
- ชื่อเมือง/จุดหมายเป็นชื่อของคนในโลกใหม่
- ถ้ามีภาพแผนที่กระดาษ ให้เว้นขอบโลกออกไปนอกภาพแทนการบีบทั้งประเทศลงในหนึ่งจอ
- ไม่มีภาพแลนด์มาร์กร่วมสมัยครบรูปจำเพาะ
- แสดงเครื่องหมาย “ข่าวไม่ยืนยัน” สำหรับเส้นทางที่ได้ยินมา ไม่ใช่สีแดงเวททุกครั้ง
- ไม่มีเข็มทิศ GPS, เลขทางหลวงยุคปัจจุบัน หรือแผนที่เลเยอร์รัฐชาติ

# 8. Mini-checklist ก่อนนำบทสนทนาไปใช้
