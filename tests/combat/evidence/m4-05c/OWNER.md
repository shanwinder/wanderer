# แบบตรวจรับ M4-05C สำหรับ Owner

## A — หลักฐานที่มีแล้ว

ทดสอบสามฉากที่ commit `fd1d00d7a63603d637f900730927a6a59e01f675` ด้วย Godot 4.7.2 ที่ 1280×720. F5 เปิด Guided Autonomous, Legacy F6 แสดง NPC 2 การ์ดให้ Player หลัง Player โจมตี, และ B5 ใช้ฉากเลือกเปิดแยกพร้อมการตัดสินใจของ NPC ตามคิวจริง. เห็นภาพพุ่งสั้นแล้วกลับตำแหน่งเดิม และ B5 แสดง HP ที่เปลี่ยนพร้อมผลกระทบ. ค่า 0.70 และ 44px ตรวจจากซอร์ส; ยังไม่มีวิดีโอวัดเวลาทีละเฟรม. [ภาพและลำดับทดสอบ](GUI.md)

ใน B5 ใช้ Tab/Shift+Tab, Enter/Space, ตัวเลือกศัตรู และคำชี้นำทั้งห้าชนิด. เห็น NPC 3 ล้ม → NPC 1 ช่วยให้ลุกที่ HP1 พร้อมใช้ RESCUE 1→0 → NPC 3 ถอนตัว. อีกช่วงเห็น NPC 2 เสียชีวิตเมื่อเวลาช่วยลดเป็น 0. เห็นทั้งชัยชนะและจบเดโมครบหกรอบโดยศัตรูยังอยู่. [ภาพและผลรายกรณี](MATRIX.md)

**ข้อเสนอของผู้ทดสอบ — HOLD เพื่อแก้คีย์บอร์ดก่อนตรวจรับ.** กด Enter ซ้ำจาก Attack แล้วเริ่มการต่อสู้ใหม่ได้ เพราะโฟกัสย้ายไป Restart ระหว่างคิว. เมื่อ Tab เข้า battle log ตอนชนะแล้ว Page Up อ่านย้อนหลังได้ แต่ Tab/Shift+Tab ออกจาก log ไม่ได้ในการทดสอบ. [ขั้นทำซ้ำและข้อเสนอแก้](FINDINGS.md)

หลักฐานอัตโนมัติครอบคลุม Player DOWN แล้วคิวเดินต่อ, RESCUE Player, HELP +4, Guard, terminal และการป้องกัน callback เก่าหลัง Restart. E5 มีหลักฐานจากชุดทดสอบที่ใช้ fault ที่ได้รับอนุญาต โดยเห็น SEALED ปฏิเสธ Restart และ Exit เปิด session ใหม่. การเล่นด้วยมือสำหรับ E5 และ benchmark §24.1 ยังไม่ได้รัน. [ผลและวิธีอ่าน trace](TRACES.md)
